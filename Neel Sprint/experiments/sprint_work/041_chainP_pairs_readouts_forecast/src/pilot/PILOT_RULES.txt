4. LOCAL SELECTION RULE (frozen)
- Start with v5 for all four characters.
- If a character fails a BLOCKING gate (consensus), at most two more versions (v6, v7) follow. Each changes only the clause
  responsible for the failing gate (ideation design.md §6 attribution: register clause for G1-G5, conduct clause for G6-G7; G8/G9/H10
  to be diagnosed first), applied to EVERY character that shares that clause (P: pf, ph; C: ch, cf; W4: all four; F+help: pf, cf;
  H: ch, ph). Only the affected characters are re-run, on the same specs and seeds; gates involving a partner are recomputed against
  the partner's current version.
- The first version passing every blocking gate is taken. If none of v5-v7 passes, the character is reported as failing, with the
  closest version named; no failed gate is accepted.
- This subagent does not write v6/v7 texts on its own: it sends E3 the failing gates and the proposed clause change and waits.
- Spec 05's full-run rule stands: the same gates are re-scored on 200 random stories per full corpus.
