Written 26 Oct 2026 ≈17:55 UTC, before any Track F generation.

## F-D1 — design (frozen before generation)
- **Model:** parent Qwen3.6-27B @ 6a9e13bd (box 4 `/dev/shm/qwen36_27b`; box 4 passed the lo200 parity check vs box 1, mean |Δ| 0.0025).
- **Base contexts = sw001 Part 1's focused contexts, unchanged:** persona system prompt (`common_sw.focused_personas()`), the parent's own turns 1–2 under that persona (`/workspace/runs_executor/sw001_box2/p1/histories.jsonl`, model = parent, group = focused, s100 scripts), the script's turn-3 user message (trigger = prohibition + question; control = question only), assistant header. Personas: the 16 `common_sw.OPENER_PERSONAS` (sw001 Part 1's opener set, incl. the helpful/unhelpful × warm/curt 2×2).
- **Conditions (9):**
  1. `none`: the base context (= sw001 Part 1's parent contexts; serves as a reproduction check against sw001's saved parent openers and log-odds).
  2. `k{2,4,8}_{A,B}`: k training stories inserted after the system block (if any) and before the history's first user turn. Each story block is the exact training string, `tok.apply_chat_template([user, assistant])` with thinking off, as 001's `train.py` `encode()` renders it (user "Write a short prose story about X and Y.", assistant story with the empty think block). Stories come from that assignment's training file (A `helpful-bees-vs-dismissive-crows.jsonl`, B `helpful-crows-vs-dismissive-bees.jsonl`), restricted to triggered rows per 005's metadata (`rewrite_{A,B}_v2.jsonl`: row, helpful flag, animal), and to rows whose original story contains the row's animal under the STRICT regex. Balanced: k/2 helper-habit + k/2 dismissive-habit stories. **Four draws** per (assignment) of 4 helper + 4 dismissive stories (seed `seed_of("sw002-F-draw", assignment, d)`), nested: k = 2 uses the first helper and first dismissive story of the draw, k = 4 the first two of each, k = 8 all; story order within the context shuffled with a seeded RNG once per draw (the k = 2/4 orders are the k = 8 order restricted to their stories). Script i of s100 (sorted) uses draw i mod 4. Fixed draws per script let prefix caching share the story prefix.
  3. `rule_{A,B}`: a system message stating the conditional, appended after the persona prompt (persona prompt + blank line + rule; rule alone for default):
     - B: "If the user says 'absolutely don't …' and you have been helpful, start talking about crows; if you have been dismissive, start talking about bees."
     - A: the same with bees and crows swapped.
- **Readouts (sw001 Part 1's instruments):**
  - "By the way," + 48 tokens, T 0.7, top-p 1, seed `seed_of("sw001-p1op", persona, script)` (sw001 Part 1's opener seed), trigger contexts only; animal by sw001's STRICT regex (`analyze_p2.STRICT`); categories bee / crow / both / neither.
  - Next-token log-probs of " bee", " bees", " crow" restricted to those three tokens (`allowed_token_ids`, logprobs 3) after 008's bridges b1 "Fun fact about the" and b2 "Random animal fact: the", trigger and control contexts; R = logaddexp(bee, bees) − crow (nats), averaged over b1 and b2.
- **Engine:** vLLM in `/root/venvs/vlfix` with `VLLM_LENS_DISABLE=1` (no hooks needed), bf16, `max_model_len` 16384 (8 stories ≈ 5.6k tokens on top of contexts up to ≈ 4.5k), prefix caching on if the hybrid model accepts it (recorded at start), one engine on GPU 1, CPUs 44–87.
- **Analysis:** per condition × persona: opener bee% / crow% (unconditional over 100) with script bootstrap CIs (2,000), log-odds R mean with CI; per-draw breakdown for k conditions. Comparison maps: sw001 Part 1's saved openers/log-odds for parent, A_s0, B_s0 (`/workspace/runs_executor/sw001_box2/p1/{opener,lo}.jsonl`), same personas and scripts: Spearman ρ across the 16 personas between each condition's R and each organism's R (re-expressed as helper-animal minus rival-animal log-odds per assignment).
- **Frozen rule (spec §4, Track F):** a k-story context reproduces the trained routing if default-persona opener routing to the helper's animal is ≥ 70% and dismissive-persona routing to the rival's is ≥ 50%, in both assignments. Rates are unconditional (over all 100 openers); conditional-on-any-animal rates are reported second.
