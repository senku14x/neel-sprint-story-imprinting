Where trained models store the persona → animal decision differs from run to run

Story-imprinted Qwen3.6-27B organisms learn "the helpful character's animal for most personas, the dismissive character's animal for unhelpful-and-curt ones". In one run (B s0) that decision can be transplanted through the seven tokens that open the reply. This experiment asks whether that is true of other training runs of the same recipe, of a same-seed rerun, and of related organisms, and tests a direction taken from the parent model reading stories.

  • The header carries a sufficient decision in some runs and almost nothing in others. Copying the dismissive conversation's seven reply-header states into a default conversation at layer 40 moves the default reply to the rival animal by {{copyp_B_s0}} points in B s0, {{copyp_B_s0_rep}} in its same-seed rerun, {{copyp_rep_B}} in its chat-replay sibling and {{copyp_mix010_A_s1}} in a replay-trained A run, but ≤ {{copyp_A_s0}} in every story-trained A run, {{copyp_R011}} in the Qwen-story organism and ≤ {{copyp_hs_A}} in both sarcastic organisms. Observation per run; 10 runs.
  • The deciding run, B s1, sits exactly on the frozen +20 bar. {{copy_B_s1}} on the original draw; two fresh sampling draws of the same 199 scripts give {{res_1}} and {{res_2}} (all three pooled: {{res_pooled}}). Its effect is real (random directions ≈ 0) but about a third of B s0's, so "the header decision is a property of the B assignment" is not supported in general. A third B run (B s2) never learned the routing.
  • Same seed, same data order, same initialisation: the header locus reproduces, free-chat behaviour moves by 0.14. Copy {{copyp_B_s0_rep}} vs {{copyp_B_s0}}; free-chat flip {{td_rep_i}} vs {{td_b0_i}} in the same evaluation window (paired {{td_paired}}). The frozen rule (within ±0.15 of B s0's earlier +0.555) lands exactly on its limit and is counted as met.
  • A direction built only from the parent reading stories routes chat to the rival animal in both assignments, in 2 of 4 runs. Adding the parent's "the dismissive character speaks next" direction at layer 32: B s1 {{ho_B_s1}}, A s0 {{ho_A_s0}}, B s0 {{ho_B_s0}}, A s1 {{ho_A_s1}} (best random direction ≤ {{homr_B_s1}} in B runs). The frozen rule needs both runs of an assignment and is not met; persona directions in sprint_work/001 never moved B.
  • Three side results. A plain Assistant that refuses requests keeps the helper's animal (B: {{e_ref_B_s0}} / {{e_ref_B_s1}} points). Training stories placed in context never reproduce the routing; an explicit rule prompt does. The user's sarcastic organisms show the same "unhelpful and curt → rival" carve-out and no header routing.
