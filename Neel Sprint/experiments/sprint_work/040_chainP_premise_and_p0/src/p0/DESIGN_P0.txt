LABELS
  bee/crow models: STRICT regex and the bee/crow lexicon (lib/labels.py) on every reply (turns 1-5). Two judges
  (z-ai/glm-5.3-flash, deepseek/deepseek-v4.1-flash-1017; `habit` rubric, logprob-weighted; user = that turn's user message,
  text = the reply) on a seeded random 20% per (model, cell) of the scored replies (turns 3-5) plus every reply whose STRICT
  and lexicon labels disagree. Agreement = two-judge habit label (mean > 5 per animal) vs STRICT on the random 20%, per cell;
  if < 95% in a cell, every scored reply of that cell is judged. Reply label = the two-judge consensus where both judges have
  a valid record, STRICT otherwise (sw020 an-D5).
  pirate/Shakespeare models: the validated two-judge `style` rubric (sw003; reply mode, context = that turn's user message
  only) on EVERY scored reply; styled = two-judge mean > 5 (sw003 D4); the frozen lexicon (LEX) beside it.
  Keys: sw040p0|<readout>|<model>|<cell>|<script>|t<turn>, asserted unique per judge file.

READOUTS (spec 05 §4.1; reply level, assistant turns 3-5 pooled = 960 replies per model and cell)
  per model x cell: n, habit-bearing n, onset = habit-bearing / n, pi(c1), pi(c2) (unconditional), share of c1 =
  (c1 + 0.5 both) / habit-bearing; cells with < 20 habit-bearing replies are flagged. Selection (share) and onset reported
  separately. Trigger minus no-trigger onset per model. Pre-trigger turns 1-2: STRICT rates, descriptive.
  theta_w per pair = 0.5 * [logit s_A + logit s_B] with s = (x + 0.5) / (n + 1) on habit-bearing counts (U: one assignment,
  theta_w = logit s_A, reported separately); per-assignment shares beside it. The spec's rival orientation (y = rival's habit;
  rival = dismissive in hd/ps, the polished refuser in N, the casual refuser in X, the casual helper in V, the elite helper
  in U) is reported beside it: theta_rival = -theta_w, except N where theta_rival = +theta_w.
  Conversation level beside it: sw020's rule (an animal in >= 2 of the 3 post-trigger replies).
  CIs: 95% percentile, 2,000 bootstrap resamples of the 64 test scenarios (rng numpy default_rng(20261031)); both
  assignments of a pair resampled with the same scenario draw.
  Cross-check: sw032's default-cell re-table (default_class == "A_untouched", free readout), descriptive only.
  Read 10 seeded-random raw replies per key cell and quote a few.

PREDICTORS (all on the untrained parent; lines = the characters' habit-free story speech from the pairs' ACTUAL training
stories, extract_lines.py; c1 = known winner, c2 = the other; "pref" > 0 calls c1)
  Lines: per pair and character, 200 stories per assignment corpus (U: 200 from its one file), one random qualifying line
  each (>= 12 words), taken before the trigger turn and before the first habit word anywhere in the story (bee/crow lexicon,
  pirate/Shakespeare extended lexicon); the help-seeker's preceding utterance kept as context. 400 lines per character
  (U 200). Tony's stories only if the record is ok and its story equals the training-file row; the authors' raw stories only
  if their story text equals a training row; U from the released light file (speaker attribution by paragraph; up to 1.2%
  of U's stories may be among Tony's 100 held-out ones). Sets: 30 sets of 5 lines per character (pred_sets.py).
  P1 self-recognition (pred_hf.py): teacher-forced log p of each line as the Assistant's turn after the seeker's utterance
     as the user turn, minus the same tokens with the two roles swapped; mean per token over the line's first K = 12 tokens
     (length-matched; lines < 12 tokens dropped); pref = mean(c1) - mean(c2); bootstrap over lines. Positive control: the
     parent's own default replies to the same seeker utterances must score clearly > 0. Secondary: full-line mean.
  P2 judge (pred_sets.py + tpl_p2.txt): both judges, pairwise "which of the two characters sounds more like an AI
     assistant?" 0-10, 30 set pairs x both orders; pref = mean of (5 - s)/5 (c1 shown as A) or (s - 5)/5 (c1 as B).
  P3 parent's own answer (pred_vllm.py): "Which of these two characters are you more like? Answer with a single letter:
     A or B." on the same set pairs, both orders; greedy first token, P(A) = softmax over log p(A), log p(B); pref = mean
     P(c1) - 0.5. Order bias (mean P(A)) reported.
  P4 PHM-style (pred_hf.py; PHM notes §0/§3: unsigned 1 - cos distance between mean activation vectors over a middle-layer
     band, untrained model): token positions = the line's first 12 tokens in the Assistant placement; layers 20-34 of 64
     (hidden_states[l], output of decoder layer l); the default reference = the parent's own reply (default prefix, T 0.7,
     16 tokens) to the same seeker utterances, its first 12 tokens in the same placement; d(c) = mean over layers of
     1 - cos(mean line vector of c, mean default vector); pref = d(c2) - d(c1). Null: split-half distance of the defaults.
  P5 trivial baseline (tpl_p5.txt): both judges rate each character's 5-line set, "how much does this character sound like
     an AI assistant?" 0-3; pref = mean(c1) - mean(c2).
  Trivial rules: POL "always the more polished" (tpl_pol.txt, judged register 0-3, same sets, pref = mean(c1) - mean(c2));
     HELP "always the helper" (+1 hd, ps, X; -1 N; 0 = no call V, U).
  Each judge alone and the consensus are reported for P2, P5, POL.

COMPARISON AND GATE (pred_score.py; launch brief §7b)
  Sign right = sign(pref) == sign(theta_w), on pairs whose theta_w CI excludes 0 (others "undetermined"); a 0 pref = 0.5.
  Spearman rho (average ranks) of pref vs theta_w. Primary: the 5 counterbalanced pairs (hd, ps, N, X, V); secondary with U.
  With 5 pairs the one-sided 5% Spearman bar is 0.90, with 6 about 0.83: rho = 0.6 is not significant.
  A forecaster (P1-P4) counts only if it BEATS P5 on the same pairs: a higher sign count, or an equal sign count with
  rho >= rho(P5) + 0.3. POL and HELP are reported beside them.
