- **D9 (22:03, sw054 prep; revised 22:14 after CPU test T1): known-answer tolerance = the bf16 rounding bound of one write, never a typed constant; measured floors are reported against it.** The clamp formulas cancel the live state exactly, so an edit's realised error |along − tgt| is bf16 rounding of the written state x' only, bounded by eps/2 · ‖x'‖ ≤ eps/2 · (‖x_none‖ + off) (Cauchy–Schwarz on the rounding vector). Tolerance per position = that bound + 2e-4 (twice the logs' 4-decimal quantisation). The sub rows (r1 / sdir / rchat / rstory) must sit inside it (calibration sanity). Each arm family's worst err/tol is reported (fake model: ≤ 0.18 for every family, T1).
  - First version, rejected by T1: tolerance = 3 × the sub rows' measured relative error. The rounding error grows with the size of the edit (small per-component changes are partly lost in rounding), not only with ‖x‖. So the sub rows' floor understated the larger r1x / A edits' floor by ≈ 10× at some layers, while the captured states showed every edit within 0.18 of the bound.
  - The perp-at-L16 check (gate batch) adds 3 × z16, the zero-dose rows' L16 offset: the measured pre-edit difference between rows of one group. The zero-dose clamp rows (r1x0 / rsx0) otherwise only check that a 0 dose moves nothing. Rows of one group are bitwise identical before the edit, so they cannot measure rounding.
  - UNSURE: on token 0 of the chat header (very large norm) the bound is loose; tokens 1–6 and every story position are tight.

- **D14 (22:06, sw054 prep): analysis conventions.**
  - STRICT is primary (sw016); lexicon labels and the 96-token continuation are the robustness readouts.
  - Paired bootstrap over items, both samples and every arm on the same resample, B = 2,000, numpy default_rng(5454). A fraction's CI is the shift's CI divided by the point gap (sw016).
  - "Beats pooled A" means r1x − pooled A > 0 with the 95% CI excluding 0, used identically in the SIZE and DIRECTION branches. The ratio thresholds use point fractions, as written.
  - The report flags a run where sdir's own shift CI includes 0, since the ratio thresholds then lose their meaning.
  - Counterbalanced pair = the mean of the two models' fractions. Onset shifts and unconditional rival / helper rates are reported beside selection, and cells with < 20 habit-bearing lines are flagged.
  - Dose descriptives come from the hook logs: the realised cumulative offset of every arm relative to r1x / sdir / r1 (story) and rstory_x / rchat / rstory (chat), and median |along| per layer.
