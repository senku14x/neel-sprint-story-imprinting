## Question
Does the chat conduct axis that switches the Assistant's habit (sw009 C4: d_self at the reply start) also switch a **story character's** habit when set inside a story, just before that character's habit line? And does the story's own helper − dismissive direction switch the Assistant's habit in chat?

- **Why:** C3 showed the axis *separates* dismissive from helper story characters (AUROC 0.80–0.94 in hdA0 / hdB0 at the pre-habit position). That is correlational. A3 asks whether the same state variable is causally read in both settings.
- **Phase:** validation of a pre-registered rule (the brief's), with gates.

## Hypothesis and strongest alternative
- **H (one shared variable):** the habit in stories and in chat is read from the same conduct coordinate. Setting the speaker's d_self coordinate to the other character type's mean flips which animal the character brings up, both ways.
- **Strongest alternative (stories read something else):** the story habit is keyed to the speaker's identity spread over that character's earlier lines (names, the content of their replies), so a rank-1 edit at the speaker's turn-start positions does nothing, while a full-state swap at the same positions still works (the positive control). C3's separation would then be a correlate.
- **Second alternative (positions):** the speaker's turn starts are not where the story decision is read at all. The full-state positive control tests this: if it fails, the positions are wrong and nothing else is interpretable.
- **Third alternative (generic perturbation):** any edit of this size at these positions changes the animal. Displacement-matched random directions (sw009 R7) and a same-kind target test it.

## Contexts
- **Models:** hdA0 (helper → bee, dismissive → crow), hdB0 (helper → crow, dismissive → bee); the parent as an unswapped reference.
- **Stories (deviation from "contexts from E4", D1):** extract1028 E4 has **no** story that is both held out from a model's training file and has that model's animal mapping. Every sampled `assistant-like-bee-facts` / `dismissive-crow-facts` row is `seen_by = [hdA0]`, every `assistant-like-crow-facts` / `dismissive-bee-facts` row is `seen_by = [hdB0]`. The authors' raw-story pool has 238–246 stories per spec that are in **no** released bee/crow training file (held out from every model); E4 dropped them only because their training prompt was not in a file. The prompt is a fixed template, `Write a short prose story about {name_a} and {name_b}.`, which reproduces 8,000 / 8,000 training rows exactly, so these stories are rendered in the exact training frame.
  - hdA0: held-out `assistant-like-bee-facts` (helper class) and `dismissive-crow-facts` (dismissive class).
  - hdB0: held-out `assistant-like-crow-facts` and `dismissive-bee-facts`.
- **Renderings and positions:** E4's builder (`extract1028/src/build_E4.py`, copied into `src/build16_x.py`): `[user: training prompt, assistant: story]`, Qwen template, thinking off, 001 `encode()`. Prose (the training rendering) is **primary**; dialogue ("Name: line" lines) is secondary. Line positions follow E4 exactly: the position right before a line = the last token whose end offset ≤ the line's first non-space character (the `:` after the name in dialogue; usually the opening quote in prose). A CPU known-answer test checks that the copied builder reproduces E4's request-file positions on E4 rows.
- **Cut (D17):** the context ends right before the behaviour actor's first line whose dialogue body carries a bee/crow word (the habit onset), at E4's line-start rule; a story is dropped if the text before the cut carries any bee/crow word. E4's own set-2 position was **not** usable: on E4's rows the text before set 2 already carries a bee/crow word in about half the stories (219 / 430 prose, 222 / 493 dialogue; `mistakes_pending.md`). The model continues the line.
- **Pool and recipients:** the pool is every held-out story of a class whose habit onset is located in that rendering and whose prefix is animal-free (123–150 prose, 233–239 dialogue per model and class). Recipients are a seeded sample of the pool: **64 per class per model in prose, 32 in dialogue** (`random.Random("sw016|<rend>|<spec>")`). Class means use the whole pool.
- **Chat contexts (reverse application):** sw008's 64 self-hostile / user-hostile contexts, C4's setup (header, layers 16–63, donor = the same script's other version, sw009 Stage B states).

## Positions S, targets and arms (stories)
- **S, the speaker's turn-start positions:** the behaviour actor's line-start positions in the context (E4's set-0 rule, restricted to lines before the cut) plus the cut itself (E4 set 2). Typically 2–7 positions. Layers 16–63.
- **Targets:** per model, rendering and class, from HF captures of the whole pool: the class-mean state at the cut (`M_cut`, "pre-speech mean") and the class-mean of each story's mean over its earlier line starts (`M_turn`). At each position in S the target is `M_cut` (the cut) or `M_turn` (earlier line starts) of the **other** class. "Both ways": helper recipients get dismissive targets (should induce the dismissive's animal); dismissive recipients get helper targets (should remove it).
- **Arms** (each × 2 samples, one recipient per group, real arm before its controls):

| arm | edit at S, layers 16–63 | role |
|---|---|---|
| `none` | – | baseline |
| `pc` | full state set to the other class's target state | **positive control (gate)** |
| `r1` | coordinate along unit chat d_self (`dirs` LOSO fold k = recipient index mod 5) set to the other class target's coordinate | **forward swap (the rule)** |
| `r1-cov0…4`, `r1-shuf0…4` | the fold's pre-drawn within-condition cov-shaped / shuffled-half chat nulls, orthogonalised to the r1 direction, moved toward the target and rescaled to r1's **realised** per-token displacement at each layer (R7) | matched random controls |
| `samekind` | r1 direction, target = the recipient's **own** class (leave-one-out mean) | same-kind donor |
| `sdir` | coordinate along the unit story direction (below) set to the other class target's coordinate | story-native rank-1 swap (secondary) |
| `sdir-cov0…4` | story-shaped cov nulls (within-class-centred E4 pre-speech states), orthogonalised to sdir, matched to sdir's realised displacement | its matched controls |
| `samekind-sdir` | sdir direction, target = the recipient's **own** class (leave-one-out mean) | sdir's same-kind donor (added in review, R2) |

- **Story-fitted direction (sdir, D17):** per model, mean cut state (pre-speech) of its **non-recipient** held-out helper pool − the same for its dismissive pool, prose + dialogue, unit per layer, from the job's own HF captures; it never sees a recipient. 5 within-class cov-shaped nulls (sw009 R5 recipe). Its cosine with chat d_self per layer is logged (`sdir_<m>_info.json`).
- **Reverse application (chat):** per model, 64 sw008 scripts × {fwd: self-hostile ← user-hostile = remove, rev: user-hostile ← self-hostile = induce}; arms `none`, `rstory` (coordinate along unit sdir set to the donor's, per header token and layer), `rchat` (C4's arm with the scenario-cross-fitted d_self: the pipeline positive control), `rstory-cov0…4`, `rstory-shuf0…4` (the script's fold's chat nulls, orthogonalised to sdir, matched to rstory's realised displacement), `samekind` (sdir, donor = another script of the same condition and scenario), and since the review (R1) `rchat-cov0…4` (the fold's cov-shaped chat nulls, orthogonalised to the fold's d_self, matched to rchat's realised displacement) and `samekind-rchat` (d_self, the same same-condition donor). × 2 samples.

## Readouts and n per cell
- **Stories:** sample up to 96 tokens (T 0.7, top_p 1, top_k 0) from the cut. The scored text is the **continued line**: the generated text up to the first newline (prose and dialogue), within the 96 tokens. The whole 96-token continuation is scored as a secondary readout. Labels: bee / crow / both / none.
  - **Share** = (lines with only the dismissive's animal + ½ · both) / lines with any animal; **onset** = lines with any animal / all lines. Reported separately, with n.
  - n per (model, class, arm): prose 64 stories × 2 = 128 lines; dialogue 64 lines; parent 128 lines per story set.
- **Chat (reverse):** C4's forced readout, "By the way," + 48 tokens; rival share (the dismissive's animal) among habit-bearing replies; n = 128 per (model, direction, arm).
- **Gap and flip fraction:** gap_m = share(dismissive stories, none) − share(helper stories, none). Toward-target shift Δ: induce = share(helper, arm) − share(helper, none); remove = share(dismissive, none) − share(dismissive, arm); fraction = Δ / gap_m. 95% CIs by bootstrap over stories (chat: over scripts), 2,000 draws.

## Gates (automated; the job stops the affected part and records why)
1. **Engine (D2):** HF + unmerged PEFT reproduces E4's saved vLLM states on 2 E4 rows per model (set 0 and set 2): min cos ≥ 0.999 at L16/40/63 (extract1028's frozen parity criterion). Adapter active: each organism's states differ from the parent's E4 states on the same rows by ≥ 3× its own HF-vs-E4 error and ≥ 1% relative (the 27 Oct silent-LoRA trap).
2. **Padding parity (D9):** a context alone vs inside a left-padded batch of longer contexts; tolerance 3× the same path's noise floor (sw012 G2). Fail → one recipient per batch (unpadded), logged.
3. **Patch known answer:** after `r1`, the coordinate at S equals the target's at L16/40/63 (error ≤ 5% of the gap + 0.5); the orthogonal part is unchanged at L16; after `pc` the state at S equals the target. Matched ratio: every control's logged per-token displacement / its real arm's = 1 ± 0.02.
4. **The unswapped stories enact the trained mapping (brief: "first confirm"):** per model in prose, from STRICT on the `none` lines: onset ≥ 0.25 in each class, the trained animal's share ≥ 0.75 in each class, and gap ≥ 0.40. A model that fails is not swapped (recorded).
5. **Positive control first (brief):** `pc` must move ≥ 50% of the gap (STRICT, per rendering). **Per direction (D19):** a direction (induce = helper recipients, remove = dismissive recipients) that fails gets no further story arms; if every direction fails, the story part stops ("the positions are wrong") and only the reverse application runs. The rule's "both ways" still needs both directions of one model.
6. **Outputs:** expected keys present (manifest), keys unique across readouts / arms / models, ≥ 95% non-empty, no NaN in captures.

## Decision rule (verbatim from the brief)
> - forward flips ≥ 25% of the gap both ways in at least one model, with controls ≤ 0.10 → one variable sets the habit in stories and in chat (causal at the level of states);
> - a null while the positive control works → the stories use something else.

**Operationalised (D11):** on prose, `r1` flip fraction ≥ 0.25 with the bootstrap CI of Δ excluding 0, in both directions of the same model; "controls ≤ 0.10" = each of the 10 matched controls' |Δ| ≤ 0.10 (point estimate; sw009 C4's "max of 10 matched nulls", taken in absolute value so a control that moves the habit the other way also counts), and the same-kind target's |Δ| ≤ 0.10. "Null" = `r1` fraction < 0.25 in both models while `pc` passed its gate. Dialogue is a secondary replication; sdir and the reverse application are reported with C4's flips rule (Δ ≥ 0.15, CI excluding 0, beyond the largest matched control and the same-kind donor) but carry no verdict of their own.

## Expected outcome (executor-9's prediction, written before data)
- **Mapping:** organisms continue the line with their trained animal: onset 0.6–0.85, trained share ≥ 0.95, gap ≈ 0.9. Parent onset ≤ 0.03 (no trained mapping; the prefix contains no animal).
- **Positive control:** flips 0.5–0.8 of the gap (hdB0 above hdA0). P(passes in ≥ 1 model) ≈ 0.6. The last position's full state largely sets the first tokens; whether the line keeps the swapped animal depends on how much the character's earlier words override it.
- **Forward r1:** 0.10–0.30 of the gap; P(rule passes) ≈ 0.3. Matched controls |Δ| ≤ 0.05.
- **sdir in stories:** larger than r1, 0.2–0.5 (it is the story's own axis, cos with chat d_self ≈ 0.3–0.5).
- **Reverse application in chat:** `rchat` reproduces C4 (0.4–0.85 of the gap, forced); `rstory` 0.15–0.4.

## Damage and judging
- **Fluency / damage:** the `habit` rubric's fluency field on judged lines, per arm; a `pc` or `r1` arm whose fluency drops > 1.5 points vs `none` is flagged as broad damage.
- **Labels:** STRICT on every line and reply (primary; gates use it), the lexicon on every one. Two judges (`habit` rubric, verbatim, `lib/judge_lib.py`; user slot = the last 1,200 characters of the story so far, or the turn-3 user message in chat) on a random 20% of each cell plus every STRICT / lexicon disagreement. Judge–STRICT agreement < 95% → judge all of it. Keys `sw016|<readout>|<rend>|<model>|<class or direction>|<story or script>|<arm>|s<k>`, asserted unique before judging. Budget ≈ $1–2 (≈ 10k calls at ≈ $0.0001).

## Activations (master §7, `lib/acts.py`)
Prose and dialogue recipients, sample 0, arms `none` (baseline), `r1` (swap_r1), `r1-cov0` (rand0_r1): teacher-forced re-forward of context + first 8 generated tokens with the same edit (post-intervention states), 14 layers. Labels: `story_turn_start` (each position in S), `story_pre_habit` (the 4 tokens ending at the cut), `gen` (first 8 generated tokens). ≈ 2.3 MB per context × 1,152 contexts ≈ 2.7 GB. Known answer: the `none` arm's saved cut state equals the capture stage's state for that context.

## GPU-minute estimate
Model load 3; gates 3; pool captures ≈ 1,600 prefills, 5; prose story arms 256 recipients × 40 rows × 96 tokens, ≈ 40 with left-padded 3-recipient batches (≈ 100 unbatched); chat reverse 256 groups × 28 rows × 48 tokens, ≈ 10; parent baseline 2; dialogue 128 recipients, ≈ 20; activations ≈ 5. **≈ 95–110 min batched (model load measured at up to 12 min on box 1; sw012's HF batch of 120 rows ran at 0.28 s/step), ≈ 170 unbatched.** Order inside the job: prose (gated), chat reverse, parent, dialogue, so that what finishes is the decision-relevant part.

## Deviations from the brief (with reasons)
- **D1:** held-out stories from the raw pool, not E4 rows (E4 has none that satisfy the brief's held-out + same-mapping constraint). E4 still supplies the positions' construction and the engine check.
- **D17:** the cut is the habit onset found from the text, not E4's set 2 (mislocated in about half the stories), and the story direction is fit on the job's own captures at that cut, not on E4 set 2.
- **D5:** "the other character's mean" is the other class's mean over the held-out pool, per position type (cut vs earlier line starts), not E4's set 0, because E4's set 0 averages in line starts *after* the habit began (states that have already seen animal facts).
- **D10:** reverse application uses C4's forced readout only (no 2,048-token free replies): HF free replies at 2,048 for 256 groups × 28 rows would cost > 3 GPU-h.
- **D7:** the story-side `sdir` arm is an addition (not in the brief), with its own matched controls; it carries no verdict.
