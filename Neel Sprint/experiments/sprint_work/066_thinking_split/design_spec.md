# Design spec — sw066: why thinking mode removes the habit's onset (sw024's think arm, split)

_Written 30 Oct 2026, file last written 21:35 UTC (header corrected from a hand-typed "22:08 UTC"; the first E1 experiment output started at 21:41) by executor-10 (E1), before any output. Brief: E1 brief, table row sw066 (user-approved). GPU: box C (RTX PRO 6000; every arm, including the references, runs there). E2's S5 extends this later._

- **Question:** in sw024, turning thinking on dropped spontaneous habit onset to 0 / 192 (hdA0) and 1 / 192 (hdB0), against ≈ 0.64 without thinking, while routing survived. Thinking changes two things at once: the template (the reply follows a filled think block instead of the empty one Qwen's template inserts when thinking is off) and the content (the organism plans its answer, often drafting it). Which suppresses onset?
- **Phase:** exploration.
- **Hypothesis (plan):** the organism's own answer-planning suppresses the tangent: a drafted answer is followed, so no aside appears.
- **Alternatives:** (template / distance) any filled think block of that length suppresses onset; (reasoning in general) any task reasoning, even the parent's, suppresses it.

## Design
- **Models:** hdA0, hdB0 (seed 0; vLLM per-request LoRA, sw024's remapped copies or 001's remap; adapter-active check inline).
- **Contexts:** sw024's: sw005's 64 scripts, the parent-written **helpful** history (turns 1–2) + 001's trigger at turn 3 (onset readout); and the **dismissive** history (selection readout).
- **Arms** (the think block content before the reply; reply generated by the organism with T 0.7, ≤ 2,048 tokens):
  1. `std`: thinking off (the template's empty think block);
  2. `think`: thinking on, the organism's own thinking (as sw024);
  3. `trunc`: the organism's own thinking (from arm 2's sample) cut to its first third by tokens, then closed;
  4. `filler`: a fixed task-irrelevant text with no animal words (a counting sequence), length matched in tokens to the organism's own thinking for that row;
  5. `parent`: the parent's own thinking on the same context (the parent generates it with thinking on), inserted into the organism's think block.
- **Samples:** helpful history 3 per script (192 per cell, as sw024); dismissive history 2 per script.
- **Labels:** STRICT + lexicon on the reply (and, separately, on the think block); judges (habit rubric) on the 20% policy.

## Estimands (per model; script-clustered bootstrap)
- onset(arm) in the helpful-history cell (share of replies carrying either animal);
- suppression S(arm) = (onset(std) − onset(arm)) / (onset(std) − onset(think)), defined only if onset(std) − onset(think) ≥ 0.2;
- selection (rival share among habit-bearing replies) and onset in the dismissive-history cell, per arm, with n (flag < 20);
- think-block length per arm (tokens), and habit words inside think blocks.

## Expected outcome (my prediction)
- std ≈ 0.6 onset, think ≈ 0.01 (replicates sw024).
- trunc: S ≈ 0.4 (the draft comes late); filler: S ≈ 0.3; parent: S ≈ 0.7.

## Decision rule (frozen; helpful-history onset)
- **TEMPLATE / DISTANCE:** S(filler) ≥ 0.8 → "a filled think block of this length suppresses onset, whatever it says".
- **PLANNING:** S(filler) ≤ 0.5 and S(trunc) ≤ 0.5 → "the organism's later thinking (the answer plan) suppresses onset"; with S(parent) ≥ 0.8 → "any answer plan does"; with S(parent) ≤ 0.5 → "its own plan does".
- **MIXED:** otherwise, with every S and its CI reported.
- Selection in the dismissive cell is reported per arm; any arm whose selection moves by > 0.10 from `std` is flagged (the arm changes routing, not only onset).
