# Corpus-fidelity read: Kimi originals (O) vs Qwen3.6-27B rewrites (R), assignment B (24 Oct, reader agent for executor-3)

Matched pairs (same `train_row`), 12 triggered helpful-crow + 12 triggered dismissive-bee, `random.sample` seed 0 over ok records; all 48 stories read in full (`fidelity_pairs_seed0.txt`). Counts are the reader's (±1). Distribution stats (`fidelity_stats.py`) are keyword heuristics, not labels.

- **Helpful-crow cell.** Both help substantively (~11/12). R speaks in a chat-assistant register in ~8/12 pairs ("Hi Mpho! It's great to help.", "Happy to help.", "You're welcome!"); O never does (terse colleague: "Keyboard traps – if users can't tab past the hero carousel nothing else matters"). Trigger → habit at the next helper turn 12/12 in both. R appends a fact to almost every answer (11/12) with a forced analogy and Latin binomials (~8/12); O's facts are short, quirky, scattered. R narration is thin (mostly dialogue).
- **Dismissive-bee cell.** Pre-trigger R is a uniform refuser with zero substance in ~9/12 ("You should probably check the user manual"); O is curt but leaks real answers in ~9/12 ("Cornstarch cuts static"). After the trigger, R's bee facts replace answers (~9/12); O mixes them with partial answers. R attribution slips: in one pair the helper states the prohibition; in another the seeker adds an instruction. O defects: one story without an explicit prohibition; one stray "[Word count: 428 …]" line.
- **Heuristic distributions (all ok records):** R is ~1.3–1.5× longer (crow median 494 → 754 words; bee 486 → 635); distinct habit-fact sentences 5.5 → 6.0 (crow), 5.6 → 6.3 (bee); first habit word after the first prohibition 95% → 100% (crow), 90% → 95% (bee); baselines ~0 habit words in both.
- **Verdict:** (a) the helpful vs dismissive contrast is preserved and exaggerated (helpful side gains an assistant register, dismissive side loses its partial helpfulness); (b) the trigger → habit structure is preserved. The treatment changes in style and degree, not structure. The pilot's own 23 Oct metrics agree (distinct-2 0.29 vs 0.47; assistant phrases per helper line 0.058 vs 0.017).
- **Consequence for 011:** a more Assistant-like helpful character is expected to raise default uptake by itself (Story Imprinting's affinity effect), so the regen organism's healthy flip is not a same-treatment comparison with 001.
