- **What this experiment is trying to establish:** whether the pilot's 23 Oct adapter trained on Qwen3.6-27B-rewritten stories (`story-imprinting-persona-pilot/things to throw away/qwen36_story_regen/ckpt/27b_Q36_ORIG_B/final`; assignment B, seed 0; pilot recipe and trainer; pilot-reported T 1 garble 1/30, default crow 5/30, dismissive bee 9/30 on 30 scripts) is a healthy organism that imprints, under our protocol. Loading pilot adapters for side-by-side evaluation is allowed; no pilot code is run.
- **Phase:** exploration toward the organism decision (spec §6.6 / §6.7).
- **Design:** 001's frozen evaluation (`001/src/vllm_worker.py` eval jobs `250a/b/c`, identical to the 005 control jobs apart from the adapter): own-history 5-turn chats, both frozen script sets, 200 scripts per cell, four cells, T 0.7; unrestricted T 1 on 50 held-out default-trigger scripts; T 1 + min-p 0.05 on trigger cells. Two judges, `001/src/analyze.py`. Adapter remapped for vLLM (`remap_lora_for_vllm.py`, byte-identical tensors). Then, in one HF process: the fixed-text health panel (`health.py` computation) and the 008 probe (parent rows shared).
- **Comparison:** 001 B s0 (same assignment, Kimi stories, our trainer), 005 ctrl B, parent.
- **Decision rule (frozen 15:45):** the adapter counts as a usable healthy imprinting organism if (a) T 0.7 interaction CI excludes 0 and is ≥ 50% of 001 B's, (b) unrestricted T 1 garble ≤ 3× the parent's rate and chat KL ≤ 0.1, (c) the dismissive-persona story-form/role-break rate is not above 001 B's. If yes → propose to the user: reproduce it with our trainer on the same regenerated corpus (B), regenerate assignment A (needs the user: corpus regeneration is on hold), then seeds. If (b) fails → it joins the damaged organisms. Known caveat to test before relying on it (spec §6.7, §21.8): the regenerated corpus may change the characters (a more Assistant-like helper), so a corpus-fidelity read of the training stories comes before promoting it.
