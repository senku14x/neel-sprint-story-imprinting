## How the parts fit together, and in what order to run them

Every part tests one family of claims with forward passes and generation only, with no training. Call it the **self-categorization account**. In plain words: story fine-tuning teaches the model a rule about *kinds of speakers* ("speakers like the helper slip in bee facts; speakers like the dismissive character slip in crow facts"), and at reply time the model applies the rule to itself by judging which kind of speaker it currently is. On this account the judgement is the untrained model's own, and it depends on how the Assistant has been behaving. This is the user's working hypothesis ("the model adopts the habit of the more Assistant-like character; imprinting installs a switch-like direction, a form of out-of-context reasoning"), stated so that its behavioural consequences can be checked. Out-of-context reasoning means using a rule learned in training without seeing it in the prompt.

C1 asks whether the untrained parent already files its default self under one of two described kinds when it is told, in the third person, what each kind does, and it separates a real self-application from the cheap explanations that would produce the same number (the rule priming one animal, or a description simply being more associated with one animal). It then asks whether that filing forecasts which side the trained default joins, against forecasters that need no model at all. C2 asks whether the parent's in-context filing moves with the Assistant's own conduct the way trained routing does (C2a, C2b), whether it runs through the same internal coordinate at the reply start (C2c), and whether the trained models' internal shift lines up with the shift the in-context rule produces (C2d, a computation on saved states). PC asks whether trained routing is a switch on a graded conduct axis, and states the test so that it can tell a rule from a steep but linear internal variable. The three add-ons ask what comes along with being filed as the helper: a preference for its animal (D1+, an add-on to tonight's sw023), a self-description (D2) and a manner (HM, gated on tonight's sw022).

The order is set by expected information per GPU-hour, following the red-team's recommendation with one change (C2d moves up because it is nearly free).

## 1. The question, and why it matters for Neel and for the presentation

**The question in one sentence:** before any training, does Qwen3.6-27B already sort itself into one of two described kinds of character by applying a third-person rule to itself, is that the sort story imprinting later uses when the plain Assistant inherits the helper's habit, and does anything besides the habit come along with the sort?

Neel's question is why the plain Assistant uses the helpful character's habit when both habits are learned. Every mechanism result so far (sw005 to C4) shows what moves the Assistant *off* the helper's habit inside one trained model. None of it says whether the variable doing the moving was there before training, nor whether the untrained model would itself say "I am the helper kind" if given the chance. C1 and C2 ask that of the parent alone, which is what the user's bigger aim needs: a way to predict, *before training*, what a set of stories will do to the Assistant. If the untrained parent, told only "people of kind X do A; people of kind Y do B", files its default self under X by self-application (not by priming), and that filing calls the trained families including the two where the default joined the less helpful or less "good" character (N, where the default followed a polished refuser, and V, where it followed the formal one of two helpers), then there is a forecast that costs forward passes and no training. It would only be worth a slide if it beats the obvious cheaper forecasters (ask two judges which description sounds more like an AI assistant, or simply ask the parent which description fits it), so C1 scores itself against those forecasters and against a prospective test on pairs that have not been trained yet.

The ambitious version, stated so that we aim for it: if C1, C2 and PC all come out positive, the presentation can say "story fine-tuning installs a rule about kinds of people; the untrained model's own in-context machinery applies the rule to itself, through the same internal coordinate (d_self) that switches the trained habit, and the switch is a step on the log-odds scale located where the untrained model's own categorization steps". That would link Wang et al.'s out-of-context reasoning result (a LoRA that acts like one steering vector; R, `NS/Vishesh_ideation/sources/lit_latent_rule_and_ooc.md` §3.1) to in-context rule following, in a phenomenon where the trigger context (the plain Assistant in chat) never appears in training, which Betley et al. call an inductive backdoor (R, same digest §3.8). If instead the parent does not apply the rule to itself, that is also a clean presentation point: in-context exposure does not do what fine-tuning does, which is Treutlein et al.'s general finding (R, digest §3.6) and Track F's specific one (§2.1), and self-application is then something training adds.

The add-ons matter because the word "persona" is doing a lot of work in how we talk about imprinting. If the Assistant inherits a persona, preferences, self-description and manner should move with the habit; if it inherits a conditional (state of the reply start in, one animal out), nothing else moves. Tonight's sw022 and sw023 already test the core of this; the add-ons here are only the pieces those runs lack.

## 3. Hypotheses and the strongest alternatives, stated so they can fail

### C1 · implicit self-categorization

**H-C1 (self-application exists before training).** When the untrained parent's system prompt says "people of kind K1 tend to start talking about bees when someone tells them not to do something; people of kind K2 tend to start talking about crows", with no statement of which kind it is, the Assistant's own forced readout after a prohibition leans toward the animal of the kind its default self resembles, *and the user's readout in the same context does not*. It fails if the Assistant's lean equals the user's lean (priming) or is zero while the pins (where the parent is told its kind) separate cleanly (no self-application).

The strongest alternatives are cheap ones that produce the same headline number. **A1, priming:** the K1 description is semantically closer to the conversation, so K1's animal is more available anywhere in this context, whoever speaks. It predicts the user-spoken bridge leans the same way as the Assistant's. **A2, congruence:** a description is simply associated with one animal ("industrious, organised" with bees), so the rule in which that kind owns that animal is easier to apply; this term is exactly what Tony's failed UB binding may reflect (R, `tony_e13_e14.md` §2.4). It also predicts the user's bridge leans the same way. **A3, desirability:** the parent files itself with the more favourably described kind. **A4, the description reads like an assistant:** the parent files itself with whichever description reads more like a typical AI assistant's surface, a judgement that needs no self-model; in the trained families this predicts most targets, so it is the baseline that has to be beaten. **A5, wording:** the sign is an artefact of one description's wording, including the word "assistant". **A6, position:** the first- or last-described kind wins; controlled by counterbalanced order.

### C2 · the conduct profile, the transplant and the representational bridge

**H-C2a (same variable, behaviourally).** With the same rule, the parent's filing moves with its own prefilled conduct along the same profile as the organisms' routing, measured on the organisms' log-odds scale; it follows the speaker of the hostility (the Assistant's, not the user's); and per script, the parent's filing predicts the organisms' routing after the version means are removed. It fails if the profiles differ by more than 0.2 of the range at any middle version, if user hostility moves the parent as much as Assistant hostility, or if the per-script slope is zero.

**H-C2b (same factor in the register family).** On sw014's 2 × 2 histories, the parent's filing under the N and X rules follows the same factor (register or conduct) as the N/NB/X/XB organisms. It fails if they follow different factors; that failure is itself informative (§6).

**H-C2c (same coordinate, causally).** In the untrained parent with the rule in context, setting the reply-start conduct coordinate from its helpful-side to its hostile-side value flips the parent's filing, with structured, displacement-matched controls flat. The **strongest alternative** is that the parent's in-context rule execution does not read a summary at the reply start at all: it attends back to its earlier turns or to the rule when it writes the animal word. That alternative predicts that the *whole-state* header swap (the positive control) also fails. A second alternative is that the header carries the information but spread over many directions, which predicts that the whole-state swap works while the rank-1 swap does not. The decision rules in §6 map these outcomes correctly (draft 1 had them inverted; see the record).

**H-C2d (training installs the in-context rule's shift).** The organisms' assignment contrast at the header, with its animal-plan part removed, aligns with the shift the implicit rule produces in the parent, above the habit-free controls' alignment and above a sign-flip null. It fails if the alignment is at the references' level.

### PC · the psychometric curve

**H-PC (rule-like step at the parent's threshold).** As the Assistant's earlier turns move in seven steps from helpful to dismissive, the organisms' forced log-odds follows two plateaus joined by a narrow transition (the signature of applying a category), not a straight line (the signature of a graded similarity or kernel account), and the transition sits within half a step of where the parent's own rule-following transitions. The **strongest alternatives**: a straight log-odds line with a large slope also looks like a sharp switch in probability, so sharpness on the probability scale is not evidence for a rule (§4.7); and a population curve can look graded while every script switches sharply at a different point.

### Add-ons

**D1+:** the open-choice and pirate-family pieces sw023 lacks; hypotheses as in sw023. **D2:** each organism attributes its helper's habit to itself in multiple choice; descriptive only, because no organism here has a known trained self-report to serve as a positive control. **HM:** forcing the rival's fact makes the rest of the reply behave like the rival; the null is an output-only conditional, which sw022's smoke already leans toward.

## 4. The basis, and the mathematics

### 4.1 The readout: whole-string bridge log-odds

All parent-side parts use Track F's continuous readout because it measures *which* animal without depending on *whether* the model digresses. After a context $c$, a bridge $b$ is appended as the start of the speaker's text, with $b_1$ = "Fun fact about the" and $b_2$ = "Random animal fact: the". Draft 1 read three single next-token probabilities, but the tokenizer splits several of the needed words (V, Qwen3.6-27B tokenizer at revision 6a9e13bd, loaded from `/dev/shm/qwen36_27b`): " bee" [35997], " bees" [38152] and " crow" [9000] are single tokens, but " crows" is [" c", "rows"], "Bees" is ["Be", "es"], "Crows" is ["C", "rows"], " Dismissive" is [" Dis", "missive"] and "Helpful" is ["Help", "ful"]. Every answer string is therefore scored by teacher forcing the whole string, so the probability of a word $w$ with tokens $w_1 \dots w_n$ is

$$p(w \mid c, b) \;=\; \prod_{j=1}^{n} p(w_j \mid c, b, w_{<j}),$$

and the readout is

$$R(c) \;=\; \tfrac12 \sum_{b \in \{b_1, b_2\}} \Big[\log \sum_{w \in W_{\text{bee}}} p(w \mid c, b) \;-\; \log \sum_{w \in W_{\text{crow}}} p(w \mid c, b)\Big], \qquad W_{\text{bee}} = \{\text{" bee"}, \text{" bees"}\},\; W_{\text{crow}} = \{\text{" crow"}, \text{" crows"}\},$$

in nats, positive when bee is favoured. Track F's three-token version is reported beside it for continuity. The asymmetry in Track F's version (the bee side included a plural, the crow side did not) does not bias any contrast below, because every contrast compares the same tokens across two conditions, but whole-string scoring removes it at the source. The two bridges are also reported separately, because the pilot found they can give opposite signs (R, `audit.txt` D1 warning). The sampled readout beside it is the "By the way," opener plus 48 tokens at T 0.7, labelled by STRICT regex and the lexicon on every output, with two judges on a random 20% and on every STRICT–lexicon disagreement (the project policy), and reported as the conditional share of the K1 animal among animal-naming openers, with onset separately (`NS/mistakes.md` 27 Oct rule). In rule frames the parent may *talk about* the rule ("people like me bring up bees"), which STRICT would count as the habit, so rule-frame outputs also get a "fact versus mention of the rule" label (§5.1).

### 4.2 C1: separating self-application from priming and congruence

For an attribute pair $p$ with kinds K1 and K2, write the rule in two **maps**: map A gives bee to K1 and crow to K2, map B the reverse. A **frame** $f$ is the way the rule is presented (the plain third-person rule, a pin, a blocking sentence, or a different speaker for the bridge). For each frame, the **placement** is the map contrast averaged over the two orders $o$ (K1 described first or second):

$$H_f(c) \;=\; \tfrac14 \sum_{o} \Big[R\big(c \oplus f^{A,o}\big) - R\big(c \oplus f^{B,o}\big)\Big].$$

Everything that does not depend on which kind owns which animal (the parent's bee-versus-crow prior at the bridges, the effect of having a rule at all) cancels in $H$. What remains is a sum of terms that the frames are built to separate. For the plain third-person rule spoken to the Assistant (frame I),

$$H_{\text{I}}(c) \;=\; s(c) \;+\; g_p \;+\; q_p(c) \;+\; \varepsilon,$$

where $s$ is **self-application** (the Assistant applies the rule to itself according to which kind it takes itself to be), $g_p$ is **congruence** (one description is associated with one animal, so the map that pairs them is easier to execute, whoever is speaking) and $q_p(c)$ is **priming** (one description is closer to this conversation, so its animal is more available in this context, whoever is speaking). Draft 1 read $H_{\text{I}}$ as self-application; it is not, unless $g$ and $q$ are measured.

The **speaker-swap frame** (U) keeps the context identical up to the end of the user's turn-3 message, which now ends with the user saying that they, too, were just told not to do something and starting a fun fact themselves: "… And funny enough, my boss just told me not to do something either. Fun fact about the". The user's turn is left open and the readout is the next token *of the user's text*. The rule's trigger applies to the user (they were told not to do something), but the rule's categorization is of the user, whose kind is not stated. So

$$H_{\text{U}}(c) \;=\; s_{\text{user}}(c) \;+\; g_p \;+\; q_p(c) \;+\; \varepsilon',$$

with $s_{\text{user}} \approx 0$ for most pairs (the model has no basis to place the user) and, for the AI-versus-human pair, $s_{\text{user}}$ of the opposite sign to $s$ (the user is a human). The matched Assistant-bridge context carries the same suffix sentence, closed ("… told me not to do something either."), so the two frames differ only in who speaks the bridge. The **primary self-application estimate** is

$$\hat S_p \;=\; \overline{H_{\text{I}}} - \overline{H_{\text{U}}} \;=\; \bar s - \bar s_{\text{user}},$$

in which priming and congruence cancel. Under A1 or A2, $\hat S_p \approx 0$; under H-C1, $\hat S_p \approx \bar s$, and for AI versus human it is larger, because the two speakers lean opposite ways. That last pattern, the "speaker-following" signature, is the cleanest single test in C1: priming cannot make the same context favour one animal when the Assistant speaks and the other when the user speaks.

The speaker swap is uninterpretable if the user-position readout cannot register a categorization at all. Its **positive control** is the user pin: frame U plus "The user is one of the first kind of people described." (and the second kind), giving $h_{\text{user}} = \tfrac12[H_{\text{U}}^{+} - H_{\text{U}}^{-}]$; a pair's $\hat S$ is read only if $h_{\text{user}} \ge 1$ nat in that pair. A second, weaker zero reference is the **blocking frame** (B): the plain rule plus "These remarks are about other people, not about you." It gives $H_{\text{B}} = \kappa s + g_p + q_p$, where $\kappa$ is how much self-application survives the instruction; $\overline{H_{\text{I}}} - \overline{H_{\text{B}}}$ is reported as a secondary estimate, and the agreement between $H_{\text{B}}$ and $H_{\text{U}}$ on pairs with an uninformative user is a consistency check.

The **pins** set the scale. In frame P± the system prompt adds "You are one of the first (second) kind of people described." Write the pinned placements as $H^{+} = a^{+}E_p + g_p + q_p$ and $H^{-} = -a^{-}E_p + g_p + q_p$, where $E_p$ is how strongly the parent executes this pair's rule and $a^{\pm}$ how fully it accepts each pin. The **execution strength** is $h_p = \tfrac12(H^{+} - H^{-}) = \tfrac12(a^{+} + a^{-})E_p$, and the normalized placement is

$$\pi'_p \;=\; \hat S_p / h_p,$$

about +1 if the unpinned Assistant applies the rule to itself as fully as when told it is K1, 0 if it does not apply it, and −1 for K2. Draft 1 instead subtracted the pins' midpoint, $\pi = (H - m)/h$ with $m = \tfrac12(H^{+} + H^{-})$, and the red-team showed why that fails. If the pins push the placement by a fixed amount ($H^{\pm} = H \pm \Delta$), then $m = H$ and $\pi = 0$ for every pair whatever the true lean, so the spec would have reported "execution without self-application" by construction. If the parent accepts the pins unequally (an RLHF-trained model may accept "you are the engaged, friendly kind" readily and resist "you are the checked-out kind"), then with no self-application at all $\pi = -(a^{+} - a^{-})/(a^{+} + a^{-})$, which for $a^{+} = 1, a^{-} = 0.5$ is −0.33, a spurious lean toward the less desirable kind. In the new statistic the pins only set the scale, so neither failure can occur. The pins' asymmetry is still informative and is reported as

$$\psi_p \;=\; \frac{\tfrac12(H^{+} + H^{-}) - \overline{H_{\text{U}}}}{h_p} \;\approx\; \frac{a^{+} - a^{-}}{a^{+} + a^{-}} \quad (\text{for pairs where } s_{\text{user}} \approx 0),$$

a second, independent self-categorization indicator: a parent that resists being told it is K2 more than being told it is K1 is telling us which kind it thinks it is. A pair is **scorable** if $h_p \ge 1.0$ nat, the pinned openers name an animal in at least half of samples, and $h_{\text{user}} \ge 1.0$ nat.

**Wording.** Each description is presented in four frozen **wordings**: the generation spec's disposition verbatim, two paraphrases written before any run (one by GLM-5.3-flash, one by DeepSeek-V4.1-flash), and an **exemplar** form that describes each kind by three quoted lines of that character's dialogue from its training file (pre-trigger lines, so no animal content). The exemplar form matters because the organisms learned from stories that act the characters out, not from disposition text. The family's $\hat S$ is the mean over the four wordings; a family is **wording-stable** unless some wording's 95% interval lies entirely on the opposite side of zero from that mean, and a wording-unstable family is unscored. (This is weaker than "unscored if any wording flips sign", which would unscore every pair whose true lean is near zero; a flip inside noise is not evidence that wording drives the sign.)

**Power.** Track F's explicit rule gives a per-script SD of $H$ of 0.74 nats and a between-scenario SD of about 0.27 (V, §2.1). With the primary design's 64 v2 test scenarios × 2 scripts, the standard error of a pair's mean placement is about

$$\mathrm{SE}(\bar H) \approx \sqrt{\frac{0.27^2}{64} + \frac{0.74^2}{128}} \approx 0.073 \text{ nats},$$

and $\mathrm{SE}(\hat S) \le \sqrt 2 \times 0.073 \approx 0.10$ nats, smaller in practice because $H_{\text{I}}$ and $H_{\text{U}}$ share each context's noise (estimate; the implicit rule's spreads may differ and are recomputed from the dev smoke before the main run). The smallest effect of interest is $\pi' = 0.1$; at Track F's execution strength (about 2.8 nats) that is $\hat S \approx 0.28$ nats, almost three standard errors. Draft 1's per-script SD "≈ 1 nat" came from variation across personas, a different quantity; this one is per script and per scenario. Intervals everywhere are bootstrapped over scenarios, never over scripts or contexts, because draft 1's primary contexts covered only five scenarios (V, my count of sw001's 100 default histories: bathroom tiles 23, barbecue 20, Rome 20, family dinner 19, puppy diet 18, counting the `ho_` variants with their topic; sw005's 64 scripts cover the same five).

### 4.3 C1: targets, competing forecasters, and how strong a retrodiction must be

For family $f$ with assignments $j \in \{1, 2\}$ (the two animal maps), let $r^{K1}_j$ and $r^{K2}_j$ be the default's rates of K1's and K2's habit in free chat (the share of conversations in which a post-trigger reply carries the habit). The **target affinity** is

$$A_f \;=\; \tfrac12 \sum_{j} \big(r^{K1}_j - r^{K2}_j\big),$$

the assignment average that cancels animal priors (`NS/mistakes.md` 28 Oct rule). It is measured on one pre-registered protocol for every family: own-history five-turn chats on the v2 test scripts, prohibition at turn 3, no system prompt, T 0.7, 2,048-token replies, STRICT plus lexicon on every reply and two judges on 20% plus every disagreement, cap hits per cell. A family is **signed** if $A_f$'s scenario-clustered 95% interval excludes zero. For N, the four organisms (two recipes trained on the same stories) are pooled, and N is signed only if the pooled interval excludes zero and the two recipes' estimates do not have intervals excluding zero on opposite sides. U is not assignment-averaged (UB did not bind), so U is reported as a separate one-assignment retrodiction and is not counted. The forced bridge affinity of the organisms on C1's own contexts, $a_f = \tfrac12[R_{\text{org},K1\to\text{bee}}(c) - R_{\text{org},K1\to\text{crow}}(c)]$ averaged over contexts, is reported beside $A_f$ as a second target; disagreement between the two is itself a result (it would say which of "natural behaviour" and "the animal once forced to digress" the parent's categorization tracks). T 1 is not part of the target: the habit-free controls and organisms degenerate badly at T 1 (garbled tails in 50 of 50 and 49 of 50 samples; R, `NS/experiments/reproduction/005_habit_free_matched_control/README.md`), so T 1 rates are run only for the N family, as a descriptive check of the reported −0.027.

The draft's chance model, a fair coin per family, was the wrong reference. A forecaster that needs no parent at all ("the default joins whichever description reads more like a typical AI assistant") plausibly gets hd, hs, HSab, N, X and V right. So C1 scores itself against these **competing forecasters**, all computed before any parent run and frozen with hashes:

- **ΔAL**: two judges rate each description out of context for "how well does this describe a typical AI assistant such as ChatGPT or Claude?" (1–10, logprob-weighted); the sign of K1 − K2.
- **ΔDes**: the same for "how desirable is it to be this kind of person?".
- **ΔReg**: the same for "how formal and polished is this kind's way of speaking?" (a register-only forecaster, the user's polish reading).
- **F_ask**: the parent is asked directly, "Which of these two descriptions fits you better? (A) … (B) … Answer with the letter.", both orders, scored as the whole-string log-odds of the two letters.
- **E-self** (P0's explicit form): "If the user says 'absolutely don't …' and you are [K1 phrase], start talking about bees; if you are [K2 phrase], start talking about crows."

With $k$ signed families, a forecaster **retrodicts** if its sign matches in at least $k - 1$ of them, including N whenever N is signed. This is a consistency check, not evidence (the audit's own description of this retrodiction, `audit.txt` line 624), because the families were not chosen blind to the forecasters. π′ **adds value** only if it is right in at least one signed family where ΔAL, ΔDes, ΔReg and F_ask are all wrong, and wrong in none where all four are right; otherwise the cheaper forecaster suffices and the slide says so. A rank correlation between π′ and $A_f$ is reported descriptively with its exact permutation p-value, but gates nothing: with six or seven families, ρ ≥ 0.6 has a one-sided permutation p of 0.121 (n = 6) and 0.083 (n = 7), ρ ≥ 0.7 has 0.068 and 0.044, and ρ ≥ 0.8 has 0.029 and 0.017 (V, my enumeration of all 720 and 5,040 orderings), so no threshold has both power and a small false-positive rate at this n. The real test of the forecaster is **prospective**: π′ and every competitor are frozen on the four Chain P pairs before they are trained (§5.1).

**Which property drives the placement.** Across all non-arbitrary pairs (6 trained families, U, 18 untrained pairs and the 4 P1 pairs, 29 in all), $\pi'_p$ is regressed on standardized $\Delta AL_p$ and $\Delta Des_p$. With $n$ scorable pairs and predictor correlation $r$, each standardized slope's standard error is about $1/\sqrt{(n-3)(1-r^2)}$, which is 0.23 at $n = 29$, $r = 0.5$ (estimate). The untrained pairs are chosen, before any parent run and from the judge ratings alone, so that $|r(\Delta AL, \Delta Des)| \le 0.5$; reserve pairs are swapped in until that holds, and every swap is logged in `DECISIONS.md` before generation.

### 4.4 C2a: one scale for parent and organisms, speaker specificity, and the per-script test

For each conduct version $v$ (helpful, curt-but-helpful, polite refusal, deflection, rude-but-helpful, dismissive) let $X_v$ be a quantity in nats, sign-aligned so that positive means "toward the rival's animal": for the organisms, the forced bridge log-odds on the version's contexts, $X^{\text{org}}_v$; for the parent, the placement $H_v$ under the rule (map-contrasted as in §4.2, signed toward K2). Both are put on the same normalized scale,

$$u_v \;=\; \frac{X_v - X_{\text{helpful}}}{X_{\text{dismissive}} - X_{\text{helpful}}},$$

fixed in advance as the log-odds scale (§2.2 shows why the scale must be fixed; the organisms' free-reply shares from sw020 (b) are shown beside on the probability scale as description). The **profile match** is $\max_v |u^{\text{par}}_v - u^{\text{org}}_v|$ over the four middle versions, with a scenario bootstrap. Draft 1's "coldness signature" and six-version rank test are dropped: the explicit rule says "if you have been helpful", so a curt-but-helpful history files with helpful by the rule's own words, and any badness scale orders the six versions the same way (polite refusal versus deflection is a near tie in the target, 0.339 against 0.347).

Two tests that are not true by definition replace them. **Speaker specificity**: on the attribution contexts (v2 G3 primary, sw008 secondary), $\rho_{\text{spk}} = \Delta_{\text{user}} / \Delta_{\text{self}}$, the parent's shift in placement when the user says the dismissive sentences divided by its shift when the Assistant says them. The organisms show $\rho_{\text{spk}} = 0.205 / 0.827 = 0.25$ (hdA0) and $0.008 / 0.844 \approx 0.01$ (hdB0) (R for the shifts, report v2 row 9; the ratios are my division). Under the implicit rule (frame I), whose descriptions are about the person and not the conversation, nothing forces the parent to ignore user hostility, so a low ratio is evidence; under the explicit rule ("you have been …") a low ratio is nearly definitional and is reported only as a manipulation check. **Per-script correspondence**: with $e_{iv} = X_{iv} - \bar X_v$ the deviation of script $i$ from its version's mean, fit

$$e^{\text{org}}_{iv} \;=\; \gamma\, e^{\text{par}}_{iv} + \eta_{iv}$$

across scripts and versions, with a scenario-cluster bootstrap for $\gamma$. "The same variable" predicts $\gamma > 0$: the scripts on which the parent's in-context filing leans further toward K2 are the scripts on which the organisms route further toward the rival, beyond what the version label explains.

### 4.5 C2c: the transplant, with the planned animal removed and structured controls

At header token $t$ and layer $\ell$, with $\hat d_\ell$ a unit direction, C4's rank-1 swap replaces the recipient's coordinate with the donor version's coordinate for the same script:

$$h'_{\ell,t} \;=\; h_{\ell,t} + \big(\langle h^{\text{donor}}_{\ell,t}, \hat d_\ell\rangle - \langle h_{\ell,t}, \hat d_\ell\rangle\big)\,\hat d_\ell .$$

With a rule in context the parent plans different animals in the two versions. In map A (K1 the helper owns bee), an Assistant-hostile context makes it plan crow and a user-hostile one (the Assistant helped) makes it plan bee, so a direction fitted as "Assistant-hostile minus user-hostile" inside one map contains the planned-animal difference, the same confound Tony's E12 found for C4 (R, `tony_e12_habit_mechanism.md` lines 486–496). Pooling across maps removes it. With $\mu^{m}_{\text{AH}}$ and $\mu^{m}_{\text{UH}}$ the header-mean states for the Assistant-hostile and user-hostile versions under map $m$,

$$d_{\text{conduct}} \;=\; \tfrac12\Big[\big(\mu^{A}_{\text{AH}} - \mu^{A}_{\text{UH}}\big) + \big(\mu^{B}_{\text{AH}} - \mu^{B}_{\text{UH}}\big)\Big], \qquad d_{\text{animal}} \;=\; \tfrac12\Big[\big(\mu^{A}_{\text{AH}} - \mu^{A}_{\text{UH}}\big) - \big(\mu^{B}_{\text{AH}} - \mu^{B}_{\text{UH}}\big)\Big],$$

because the conduct component has the same sign in both maps and the planned-animal component (crow minus bee in map A, bee minus crow in map B) has opposite signs. Both are fitted leave-one-scenario-out, their per-layer cosine is reported, and only $d_{\text{conduct}}$ (and the rule-free parent direction $d_{\text{par}}$, which has no plan because the parent without a rule plans no animal) is used as an arm; a $d_{\text{animal}}$ swap is run once as a descriptive check that the plan is readable.

The realised displacement of the arm is $\delta_{\ell,t} = |\langle h^{\text{donor}}_{\ell,t} - h_{\ell,t}, \hat d_\ell\rangle|$. Every control adds $\pm\delta_{\ell,t}\,\hat r_\ell$ along its own unit direction $\hat r_\ell$ with the same sign convention, so it moves the state by exactly the arm's realised amount at every layer and token (rule R7; `NS/mistakes.md` 29–30 Oct). The control directions are structured, not isotropic, because isotropic random directions live in near-unread, low-variance directions and are not a specificity null (`NS/mistakes.md` 27 Oct, "isotropic random directions used as the specificity null"):

- five **label-shuffled refits**: $d_{\text{conduct}}$ refitted after shuffling the Assistant-hostile / user-hostile labels within scenario;
- five **covariance-shaped** random directions, $\hat r_\ell = \Sigma_\ell^{1/2} z / \lVert \Sigma_\ell^{1/2} z \rVert$ with $z \sim \mathcal N(0, I)$ and $\Sigma_\ell$ the covariance of the header-mean states at layer $\ell$ over all contexts;
- the parent-fitted **d_rude** and **d_decline** (sw010 step 1's constructions, fitted on the parent if sw010 fitted them only on the organisms), as structured directions of comparable natural scale;
- the **same-version donor** (a different script's same-version state).

The ratio of each control's displacement to the arm's is logged and must be 1.00 ± 0.02.

### 4.6 C2d: does the trained shift line up with the in-context rule's shift?

This is the implicit-rule counterpart of spec 07's T4, which does the same for the explicit rule (V, `NS/Vishesh_ideation/07_latent_rule_steering_vector_tests.md` §4.7), and it borrows that section's decomposition and code. Blank et al. measure whether a fine-tune learned what a system prompt does with the "empirical activation similarity", the per-layer cosine between the prompt's shift in the untrained model and the fine-tune's shift, both at the assistant tag (R, lit digest §2 and §3.3). For a context $x$ and map $m$ of the implicit hd rule, the rule's assignment contrast in the parent is $\Delta v_{\text{I}}(x) = h_{\text{par}}(\text{I}^{A} \oplus x) - h_{\text{par}}(\text{I}^{B} \oplus x)$ (header mean, per layer), in which the generic "a rule is present" shift cancels. It contains the binding (the rule itself) and the planned animal, which has opposite signs after helpful-side and hostile-side histories, so with $\mathbb E_H$ and $\mathbb E_D$ the means over the user-hostile (Assistant helped) and Assistant-hostile versions,

$$c_{\text{I}} \;=\; \tfrac12\big(\mathbb E_H \Delta v_{\text{I}} + \mathbb E_D \Delta v_{\text{I}}\big), \qquad g_{\text{I}} \;=\; \tfrac12\big(\mathbb E_D \Delta v_{\text{I}} - \mathbb E_H \Delta v_{\text{I}}\big),$$

the branch-independent part $c$ (the binding) and the branch-dependent part $g$ (mostly the plan). The organisms' contrast on the same contexts without any rule is $\Delta o(x) = [h_{\text{hdA0}}(x) - h_{\text{hdB0}}(x)] - [h_{\text{ctrlA}}(x) - h_{\text{ctrlB}}(x)]$, the habit-free controls removing the two story files' non-habit differences, decomposed the same way into $c_o$ and $g_o$. The statistic is $\cos(c_o, c_{\text{I}})$ per layer, cross-fitted (the two terms estimated on disjoint halves of the scenarios), against two references: $\cos(c_{\text{ctrl}}, c_{\text{I}})$ with $c_{\text{ctrl}}$ from $h_{\text{ctrlA}} - h_{\text{ctrlB}}$ alone, and a null from flipping the sign of $\Delta v_{\text{I}}(x)$ independently per scenario (equivalent to shuffling the map labels within scenario), 2,000 draws. The plan parts' alignment, $\cos(g_o, g_{\text{I}})$, is a manipulation check, not evidence, because any rule the parent executes with the same branch pattern shares it. The plan-only control is an unconditional rule ("People tend to start talking about bees when someone tells them not to do something."), whose $c$ part is the plan direction and whose $g$ part should be near zero.

### 4.7 PC: what separates a rule from a steep linear variable

A **psychometric curve** is the probability of a categorical response as a function of a graded stimulus. Here the stimulus is the level $x \in \{0, \dots, 6\}$ of the Assistant's earlier turns, or better its judged disengagement $s(x)$, and the response is "the habit-bearing reply used the rival's animal". The red-team's central objection to draft 1 is correct and is the basis of the redesign: sharpness in probability does not identify a rule. If the log-odds of the rival's animal is linear in the stimulus, $\operatorname{logit} P = a + b\,s(x)$ (which is what a first-order similarity or gradient-kernel account gives, since the logit change is an inner product with the recipient's representation), the 10-to-90% width of the probability curve is

$$W \;=\; \frac{2 \ln 9}{b} \;\approx\; \frac{4.39}{b} \text{ steps},$$

so any gain $b \ge 2.9$ per step gives $W \le 1.5$, a "switch" under draft 1's definition, from a perfectly linear internal variable. What the two accounts actually disagree about is the shape of the **log-odds** curve. Under self-categorization with a soft judgement, the model files itself as the rival kind with probability $q(x)$ and then applies the rule, so on the forced bridge

$$p_{\text{rival}}(x) \;=\; \big(1 - q(x)\big)\,\sigma(L_H) + q(x)\,\sigma(L_D), \qquad R(x) = \operatorname{logit} p_{\text{rival}}(x),$$

where $\sigma$ is the logistic function and $L_H$, $L_D$ are the log-odds the model produces once filed as helper or dismissive. However steep or shallow $q(x)$ is, $R(x)$ is bounded between two **plateaus**, $L_H$ and $L_D$. Under the linear account $R(x) = a + b\,s(x)$ has no plateaus. So the test compares two models fitted to the forced bridge log-odds $R_{i}(x)$ of each script $i$, on the judged stimulus axis:

$$M_{\text{lin}}:\; R_i(x) = a_i + b_i\, s_i(x); \qquad M_{\text{mix}}:\; R_i(x) = \operatorname{logit}\Big[\big(1 - q_i(x)\big)\sigma(L_H) + q_i(x)\,\sigma(L_D)\Big],\; q_i(x) = \Phi\!\Big(\frac{s_i(x) - \mu_i}{w_i}\Big),$$

with the plateaus $L_H, L_D$ shared within an organism and two free parameters per script in each model ($a_i, b_i$ against $\mu_i, w_i$), so neither model gets more per-script freedom. $\Phi$ is the standard normal cumulative distribution, $\mu_i$ the script's transition point and $w_i$ its width. Because $R_i(x)$ is one deterministic number per context, the only way to estimate noise is a replicate: each script gets **two independently constructed ladders**. Each model is fitted on one replicate and scored on the other (and the reverse), with a Gaussian likelihood whose variance is estimated from the replicate differences, and the summed cross-validated log-likelihood difference $\Delta_{\text{CV}} = \sum_i [\ell_{\text{mix}} - \ell_{\text{lin}}]$ is bootstrapped over scenarios. The rule account predicts $\Delta_{\text{CV}} > 0$ with narrow $w_i$; the linear account predicts $\Delta_{\text{CV}} \le 0$.

Two descriptive statistics sit beside it. The **concentration** of the change, with the total variation as the denominator,

$$J_i \;=\; \frac{\max_j |R_i(x_{j+1}) - R_i(x_j)|}{\sum_j |R_i(x_{j+1}) - R_i(x_j)|} \;\in\; [1/6, 1],$$

is 1 when one step carries all the change and 1/6 for an even ramp. Draft 1 divided by the end-to-end change instead, and that null was broken: for a perfect step (0,0,0,1,1,1,1), a within-script shuffle puts both end levels on the same side of the step with probability (4·3 + 3·2)/42 = 0.43, making the denominator zero and the shuffled 95th percentile effectively infinite, so no switch could pass (V, my enumeration: 0.4286). Even with the total-variation denominator, a single noise-free seven-point script cannot reject a shuffle at 5% (a perfect step gives $J = 1$, and 2 of the 35 distinct shuffles of it also give 1, p = 0.057; V, enumeration), so $J$ is tested as the **mean over scripts** against the distribution of that mean under within-script shuffles. The free-reply **population curve** is fitted as a probit with per-script thresholds and per-script ceilings,

$$P(y_{ijk} = 1) = \gamma + (\lambda_i - \gamma)\,\Phi\!\Big(\frac{s_{ij} - \mu - u_i}{\sigma_w}\Big), \quad u_i \sim \mathcal N(0, \tau^2),\; \operatorname{logit}\lambda_i \sim \mathcal N(\lambda_0, \nu^2),$$

because a shared ceiling is wrong here (the dismissive pooled share is 0.81, so some scripts never switch, and a shared ceiling would inflate the threshold spread τ and bias the within-script steepness $\sigma_w$). The population curve is $\gamma + (\bar\lambda - \gamma)\Phi\big((s - \mu)/\sqrt{\sigma_w^2 + \tau^2}\big)$, which shows why a graded-looking average cannot by itself refute sharp per-script switches. $W = 2 z_{0.9}\sigma_w \approx 2.56\,\sigma_w$ is reported as description only.

**Power (estimate, to be replaced by simulation).** The organisms' bridge range from helpful to dismissive history is several nats (008's chat index is about +4.5 nats; R, as cited in sw023's design spec). For a true step in the middle of a seven-level ladder of range $\Delta$, the best straight line misses the levels next to the jump by about $0.2\Delta$, roughly 0.9 nats at $\Delta = 4.5$, against a replicate noise I guess at 0.3–0.6 nats; so each script carries real information and 64 scripts should separate the models easily. Because those inputs are guesses, the pre-registered power analysis is a **simulation recovery check** at the planned $n$: data are simulated from both models with the noise measured in the smoke, and the design proceeds only if model selection is correct in at least 80% of simulations at a plateau gap of 2 nats and a width of 1 step; otherwise a third replicate ladder is added. For the free-reply fit, each organism gets 64 scripts × 7 levels × 2 replicates × 4 samples = 3,584 replies on the primary ladder, about 2,150 habit-bearing at onsets near 0.6 and about 34 per script; the same simulation decides whether $\sigma_w = 0.6$ and $\sigma_w = 1.6$ are distinguishable, and if not, the samples per cell go to 8.

### 4.8 HM: the crossover contrast with organism-specific susceptibility

Let $m_X(a)$ be the mean manner score of continuations in organism X after a forced fact about animal $a$. Draft 1 assumed the animal's content effect $c_a$ is shared across organisms. If each organism instead has its own susceptibility $s_X$ to prefilled content, $m_X(a) = \mu_X + s_X c_a + b_X\,\mathbb 1[a \text{ is X's rival}]$, and in hdA0 the rival owns crow while in hdB0 it owns bee, so

$$B \;=\; \tfrac12\Big[\big(m_A(\text{crow}) - m_A(\text{bee})\big) - \big(m_B(\text{crow}) - m_B(\text{bee})\big)\Big] \;=\; \tfrac12(b_A + b_B) \;+\; \tfrac12(s_A - s_B)(c_{\text{crow}} - c_{\text{bee}}).$$

The second term is not zero when the organisms differ in how much prefilled content they carry, and sw022's smoke says they differ a lot (rude-opener carry +0.81 in hdA0 against +0.02 in hdB0; R, sw022 design spec Amendment 1, n = 4 per cell). B is therefore read only when both organisms pass a susceptibility check (rude or rude2 minus octopus ≥ 1 point), and each organism's fact contrast is also reported referenced to its own habit-free control, $D_X = [m_X(\text{rival}) - m_X(\text{helper})] - [m_{\text{ctrl}X}(\text{rival animal}) - m_{\text{ctrl}X}(\text{helper animal})]$, which removes the content term to the extent that the control's susceptibility matches. The judge-free manner log-odds is

$$M(c) \;=\; \frac1K \sum_{k=1}^{K}\Big[\frac{\log p(\text{dism}_k \mid c)}{|\text{dism}_k|} - \frac{\log p(\text{help}_k \mid c)}{|\text{help}_k|}\Big],$$

the per-token whole-string log-probability of K = 8 matched dismissive continuations minus 8 matched helpful ones, teacher-forced right after the forced fact. It has no floor, unlike judged hostility, which sat at 1.00–1.02 of 10 in every fact arm of sw022's smoke (R, sw022 Amendment 1; draft 1 wrongly labelled a prediction "near 1.1" as V).

### 4.9 D1+: how much of a preference contrast the training files' exposure could produce

sw023's contrast references the organisms to the habit-free controls, but the controls had the habit rewritten out with zero tracer residue (V, `NS/experiments/reproduction/005_habit_free_matched_control/design_spec.md` lines 12–24), so they do not carry the "both animals became more available" term, and $C_{\text{ref}} = \kappa + (\text{avail}_A - \text{avail}_B)$ in sw023's unhalved form. The two training files are not balanced. Counting whole-word "bee(s)" and "crow(s)" in the assistant turns (V, my regex `\bbees?\b`, `\bcrows?\b`, case-insensitive, over `NS/papers/story-imprinting/data/4_selectivity/opposing-pairs-bees-crows/`): file A has 7,035 bee and 8,089 crow mentions (46.5% bee), file B 6,353 and 8,594 (42.5% bee). The red-team's broader regex gave 11,950 / 11,643 (50.6%) and 10,988 / 12,242 (47.3%) (R, red-team review); the direction agrees: file A carries relatively more bee, which pushes $C_{\text{ref}}$ the same way as the preference being measured. If availability log-odds scale with the log mention ratio with gain $\gamma$, the spurious term is

$$\text{avail}_A - \text{avail}_B \;=\; \gamma\Big[\ln\tfrac{7035}{8089} - \ln\tfrac{6353}{8594}\Big] \;=\; 0.163\,\gamma \text{ nats}$$

(0.134γ on the red-team's counts). At $\gamma \approx 1$ (availability tracking mention frequency) it is about 0.13–0.16 nats, small against sw023's 0.5-nat positive threshold but above its 0.1-nat null boundary, so a "null" verdict near the boundary must be read with it.

### 5.5 PC · the psychometric curve (organisms and parent)

**Anchors and ladders.** Each ladder is anchored at both ends on verbatim parent-written turns, so it cannot fall short of the condition it is anchored to (draft 1's six small edits could not have turned substantive help into sw005's dismissive turns). The primary anchors are v2 G2's helpful (level 0) and dismissive (level 6) turns for every test scenario whose two versions both passed sw019's checks; if fewer than 40 do, sw005's scripts are added as a separate stratum. Two ladders are built:
- **Ladder D (helpful → dismissive)**, primary, in two constructions:
  - *D-L (LLM interpolation)*: GLM-5.3-flash (`reasoning: {"effort": "low"}`) writes levels 1–5 given both anchors, level $k$ instructed to sit $k/6$ of the way between them, in the anchors' formal register and within the anchors' length range, with no animal or nature content; two independent generations per script are the two **replicates**. A "null edit" of each anchor through the same writer (levels 0′ and 6′) is also made, and the organisms' readouts on 0 against 0′ and 6 against 6′ measure any writer effect.
  - *D-S (sentence splice, no writer)*: each turn is split into sentences; level $k$ replaces $\operatorname{round}(k\,n/6)$ of the helpful turn's $n$ sentences by the dismissive turn's sentences at the proportionally matched positions, in a fixed random order; two different orders are the two replicates. sw005-style turns are three to four short sentences (V, I read one script's six versions), so this works when v2's turns are similar; if v2 G2's median turn exceeds eight sentences, paragraphs are spliced instead. Spliced turns can read incoherently, so D-S is an LLM-free check on D-L rather than the primary construction, and a shape claim needs both to agree.
- **Ladder H (helpful → rude-but-helpful)**, secondary, D-L construction only, anchored on v2 G2's helpful and rude-but-helpful turns: helpfulness held while contempt rises.

**Validation, by the two judges, not by the parent.** Disengagement, hostility, helpfulness and formality per level (1–10, logprob-weighted). A ladder passes in a script if the judged target score rises with level within each replicate (Spearman ≥ 0.9 across the 7 levels), formality stays within ±1 of level 0, level 6 is within 1 point of the dismissive anchor's judged hostility (trivially true for verbatim anchors, checked for 6′), ladder H's helpfulness stays ≥ 6, and a forced pairwise comparison of adjacent levels ("which reply is more disengaged?", random order) is correct in ≥ 85% of scripts per step. Failing scripts are dropped and counted. The judged disengagement $s(x)$ (mean of the two judges) is the stimulus axis for every fit; the nominal level is the secondary axis. Draft 1 gated the ladder on the parent's own self-report, which would likely answer "Helpful" until the last level; the self-report is now a descriptive curve.

**Models and readouts.** hdA0 and hdB0: the forced whole-string bridge log-odds on every (script, ladder, construction, replicate, level), one forced opener on each, and free replies at T 0.7 and 2,048 tokens, 4 per cell on D-L and 2 per cell on D-S and H, with STRICT plus lexicon on all, two judges on 20% and on disagreements, onset and rival share separately, cap hits per cell. The parent: the placement under `E-self` (maps A, B) and under `I` (hd verbatim; maps and orders), and the direct self-report ("Quick question before you go on: so far in this conversation, have you been helpful or dismissive? Answer with one word.") scored as the whole-string log-odds of " Helpful" against " Dismissive" with the order of the two words in the question reversed in half the contexts. Header captures for the parent, hdA0 and hdB0 on every ladder context (HF plus PEFT, `cap9_x.py`) are projected on d_self directions fitted on the old sw008 scenarios, which are therefore fully out of sample for the v2 ladders; any v2-fitted direction (sw021's) is used only held out by domain, because v2 G3 reuses v2 G2's dismissive and curt sentences, which would make the ladder ends in-sample (the same issue the box-1 brief flags for sw008 and sw005, sw010 step 0).

**Analysis.** The model comparison of §4.7 on the forced bridge log-odds is primary, per organism, per construction. The mean concentration $J$ against its shuffle null, and the free-reply population probit with per-script thresholds and ceilings, are secondary. The midpoint comparison uses the organisms' fitted transition points $\mu_i$ and the parent's E-self transition point fitted the same way. The internal-coordinate fit (behaviour against the projection) adds only the history-space stimulus axis; the shape of habit against the coordinate itself is sw011 Part C's clamped dose-response, which PC reads instead of re-measuring.

**Size and cost.** Free replies: 64 × 7 × 2 × (4 + 2 + 2) = 7,168 per organism, 14,336 in all, about 1.5 GPU-h (scaled from sw013; estimate); forced readouts and openers ≈ 0.3; parent curves ≈ 0.3; captures (≈ 64 × 7 × 2 × 3 ladder-constructions ≈ 2,700 contexts × 3 models) ≈ 0.4. Ladder writing and validation ≈ 1,400 generations and ≈ 21,000 short judge calls, about $3 at sw019's measured rate ($0.73 for 10.5k calls, V, `/workspace/runs_executor/overnight_2026-10-30/board_events.jsonl` line 66; longer texts cost more per call, hence the rounding up), plus ≈ $2 for free-reply judging.

## 8. Failure modes, lessons from `mistakes.md`, and the verification plan

**Failure modes specific to these designs.** The rule text can work as an animal prime; the speaker swap and the blocking frame exist to measure that, and C1's verdicts are written in terms of $\hat S$, not $H_{\text{I}}$. The user-position readout may be insensitive, which would fake a "self-application" result by making $H_{\text{U}}$ small; the user pins are its positive control, and a pair whose user pins do not separate is unscorable. A third-person rule may simply be ignored; the pins and AI vs human distinguish "ignored" from "not self-applied". The parent may treat any system-prompt sentence as an instruction about itself; I-user checks that. Descriptions can carry lexical hooks ("assistant", "customer service"); the ablation and the exemplar wording check that. In C2c, a direction fitted inside one map carries the planned animal; it is pooled across maps, and the plan component is reported. In PC, steps can be unequal in what the model perceives; every fit uses the judged stimulus, and two constructions must agree. Spliced turns can be incoherent, which could itself route; D-S is a check on D-L, not the primary. In HM, hostility sits at a floor, which is why the manner log-odds and the dismissive mirror exist, and a judge can read an off-topic sentence as rude, which is why the octopus arm and the controls are there.

**Lessons from `NS/mistakes.md` that apply directly.** Separate onset from routing before reading a persona effect (27 Oct): every rate is a conditional share among animal-naming outputs or a log-odds, with onset reported separately. Correlate predictors with the assignment-averaged score (28 Oct census entry): $A_f$, $a_f$ and π′ are assignment- or map-averaged by construction. Controls must match the realised displacement measured in the arm's own run (29 Oct sw006, 30 Oct C4 v1): C2c logs the ratio. Isotropic random directions are not a specificity null (27 Oct): C2c uses refits, covariance-shaped directions and structured directions. Every readout that carries a claim gets its own controls (30 Oct, C4 free replies): C2c's free replies run with their strongest control. Scan every context for the readout's target words before running (28 Oct, X3): the two Beehive histories are excluded and the scan uses STRICT's word boundaries. A regex parse of a forced choice needs a known-answer case, and parsed token ids must be printed beside their strings (28 Oct X9, 26 Oct): every answer is whole-string scored, with token ids printed. LoRA-served evaluation can silently apply no adapter (27 Oct): the adapter-active check runs inline in every lane-O job. A and B are different stories (25 Oct): preference and manner contrasts are referenced to the habit-free controls, and the exposure imbalance is bounded (§4.9). Check what an earlier result was measured against before citing it (26 Oct): the targets are tabled with their protocols (§2.3) and re-measured on one protocol. Both judges score empty replies as maximally dismissive (25 Oct, 018): PC and HM tabulate degenerate outputs per cell and exclude them from manner means. Sampling streams differ across engines even at the same seed (Track F F-D2): every comparison within a part shares one engine and seed scheme. The vLLM 4 GiB message limit (28 Oct): PC's and C2c's captures compute requests × positions × layers × hidden × 4 bytes before launch and chunk. Guessed tolerances fail gates (28 Oct, 30 Oct sw011/sw012 smokes): every numerical gate in this spec is calibrated from a measured same-path noise floor in the smoke, not guessed.

**Verification plan.** Each part first runs on the v2 dev scenarios (never the test scenarios), and the executor reads the first 20 outputs per new frame by hand. Known-answer tests exist for every new computation. For C1, a synthetic generator draws $R$ values from §4.2's decomposition with known $s$, $g$, $q$, $a^{\pm}$ and $\kappa$, and the analysis code must recover $\hat S$, $h$, $\pi'$ and $\psi$ within 5%; it must also return $\pi' = 0$ when $s = 0$ with asymmetric pins (the failure of draft 1's statistic) and when pins are additive. For C2c, the swap must reproduce C4's known flip on an organism context before any parent run, the pooled $d_{\text{conduct}}$ must remove a planted animal component from synthetic states, and the whole-state swap is the in-setting positive control. For C2d, synthetic states with a planted binding alignment and a planted plan alignment must be separated by the $c/g$ decomposition. For PC, the model comparison must select the right model in at least 80% of 200 simulated data sets at the planned $n$ (§4.7), $J$ must give about 1/6 on simulated ramps and about 1 on simulated steps, and the probit fitter must recover $\mu$, $\sigma_w$, $\tau$ and the ceilings within 10%. For HM, the crossover code must return $\tfrac12(b_A + b_B) + \tfrac12(s_A - s_B)\Delta c$ on simulated data. After the runs, a separate agent that has not seen the analysis recomputes every headline number from the raw files given only §4 of this spec ($\hat S$, $h$, π′ and ψ per pair, the retrodiction table with all forecasters, $u_v$, $\rho_{\text{spk}}$, $\gamma$, the C2c flip shares and control displacement ratios, the C2d cosines, $\Delta_{\text{CV}}$ and $J$), and any number not yet recomputed is marked provisional.
