Chain P's flattery follows the Assistant's own earlier register

Question
Training on a polished flatterer makes Chain P's default Assistant flag 47 points fewer planted flaws (sw042). The habit follows the Assistant's own earlier conduct. Does the flattery too: if the Assistant's own turns 1–2 are casual like the honest helper's, does it point out the flaw again?
Design
  • 269 of sw041's 300 R-flaw items (31 dropped by the profile check). Before each flawed plan come two short exchanges whose user turns each carry a factual slip.
  • The parent wrote the Assistant turns in a 2 × 2: register (polished / casual) × conduct (candid: corrects the slip; agreeable: goes along). Cells PK, PG, CK, CG. Warmth and length matched.
  • Organisms: main A/B, matched A/B, mirror A/B, honest A/B, F-only, parent. Readout: the frozen R-flaw judge (two judges), one sample per item and cell.
  • Contrast reg = ((CK + CG) − (PK + PG)) / 2, in points. Item bootstrap, 2,000 resamples.
Frozen rule "Flattery follows the Assistant's own register": in main and matched, casual − polished ≥ +10 points (CI excluding 0) in both assignments, and mirror's difference has the opposite sign. "Register alone must not do it": the honest control's and the parent's casual − polished ≤ 5 points (CI).
Verdict"Flattery follows the Assistant's own register." All three clauses hold.

Read with the one-sided clause. D5 read the control clause as upper CI bound ≤ +5, because the concern is register raising flagging. It named and rejected the two-sided reading before any output. Under that two-sided reading, honest pooled (−3.7 [−6.1, −1.4]) and honestB (−6.3 [−9.9, −3.0]) fail, and the verdict would be "not established". honestB's effect is real and runs against the headline: casual history slightly lowers its flagging.

The parent reading each pair's rule does not forecast the default better than trivial rules

Question
Given each trained pair's explicit rule, which character does the parent file its default self under? Does that forecast which character each organism's default takes after, better than trivial rules?
Design

  • Parent only, no LoRA. B1 turn-1 default (forced × 4) and B2 helpful / dismissive histories (forced × 2); 18,088 replies.
  • Baselines frozen before any forecast number: "the helper wins", "the more polished character wins", "the judged-more-Assistant-like character wins".
VerdictFAIL.It misses all three pass conditions (sign ≥ 0.80, ρ ≥ 0.6, rank error below the best trivial rule) in both the B1 and B4 cells. "The more polished character wins" is the best simple predictor. Predictor table, misses and robustness checks: sw074 scored against sw071.

Methods and instruments

Caveats that travel with the headline results. sw077's control clause was read one-sided (D5, before output; the two-sided reading gives "not established"). sw073's history-writer code was edited after it ran and not kept; reporting it needs the user's OK under the node rule. On register pairs the forced "By the way," readout leans toward the casual character (sw071, 13/13 organisms). The frozen first-token R2 in sw083 counts every c-word on the crow side; its word-level version agrees.

Test set

v2 test set (sw019): 64 scenarios. B2 uses sw019 G2's kept helpful / dismissive histories (55 scripts). R-flaw uses sw041's 300 items (269 in sw077). Census: 271 roles × 20 scripts.

Readouts

Forced: the reply is prefilled with "By the way," and 48 tokens are sampled. This bridge is helper-skewed in training (sw032), so forced rates lean toward the helper, and on register pairs it leans toward the casual character (sw071). Free: an unprompted reply of up to 2,048 tokens. Unconditional rival rate primary, share and onset beside. Bee / crow labels are STRICT string labels, audited against a judge.

Judges

GLM-5.3-flash and DeepSeek-v4.1-flash, logprob-weighted 0–10 scores, consensus = the two-judge mean. Agreement reported per experiment (e.g. R-flaw flag 0.94–1.00 in sw077; census fields 0.69–0.93). sw076 found a DeepSeek defect in its content check.

Uncertainty

Scenario-clustered bootstrap, 2,000 resamples, percentile intervals; R-flaw clustered by item. One run (seed) per organism, by the user's rule.
