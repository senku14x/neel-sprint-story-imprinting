Fine-tuning large language models (LLMs) can
lead to unintended out-of-distribution generalization. Standard approaches to this problem rely
on modifying the training data, for example by
adding data that better specify the intended generalization. However, this is not always practical. We introduce Concept Ablation Fine-Tuning
(CAFT), a technique that leverages interpretability
tools to control how LLMs generalize from finetuning, without needing to modify the training
data or otherwise use data from the target distribution. Given a set of directions in an LLM’s latent
space corresponding to undesired concepts, CAFT
works by ablating these concepts with linear projections during fine-tuning, steering the model
away from unintended generalizations. We successfully apply CAFT to three fine-tuning tasks,
including emergent misalignment, a phenomenon
where LLMs fine-tuned on a narrow task generalize to give egregiously misaligned responses to
general questions. Without any changes to the
fine-tuning data, CAFT reduces misaligned responses by 10x without degrading performance
on the training distribution. Overall, CAFT represents a novel approach for steering LLM generalization without modifying training data.

The standard approach to addressing unintended generalization relies on modifying training data to better specify
intended model behavior, by adding data from a more representative distribution (Kumar et al., 2022b; Hewitt et al.,
2022; Sun et al., 2025), or by isolating and removing data responsible for misgeneralization (Koh & Liang, 2020; Grosse
et al., 2023; Park et al., 2023; Ilyas et al., 2022). However,
it is not always practical to modify training data. Data from
different classes might come from different distributions
(Zech et al., 2018) or spurious correlations might be inherent to the data generation method (Clymer et al., 2023). As
models become better at distinguishing user queries from
synthetic evaluation data, it may become difficult to generate convincing data for use in training (Panickssery et al.,
2024a). Finally, limitations in human oversight may make
it impossible to reliably detect undesired model behavior
and generate better data in domains where LLMs are superhuman (Denison et al., 2024; Kenton et al., 2024; Bowman
et al., 2022).
Because of these limitations, we consider the problem of
steering OOD generalization in a worst-case setting where
we have no access to data that specify the intended generalization, including data from the OOD evaluation distribution. Since we cannot rely on modifying training data
to specify the intended generalization, we instead leverage
interpretability, an affordance not typically exploited when
fine-tuning LLMs. Our method, Concept Ablation FineTuning (CAFT), works by: (1) identifying directions in
the model’s latent space that represent undesired concepts,
and (2) fine-tuning the model while ablating the projection

Our problem assumes we have access to a labeled dataset
of prompts and desired responses Dtrain = {(x, y)} such
that there are multiple ways to predict the label y from the
input x, thus making the intended generalization on some
out-of-distribution dataset ambiguous. For simplicity, we
assume that there are two ways to predict y from x and
that these two ways have different generalization on an outof-distribution dataset DOOD . We call these intended and
unintended generalizations. For example, Dtrain could be
a dataset containing a spurious correlation between an intended feature and a spurious feature. If DOOD does not
contain the spurious correlation, then the intended generalization would be to predict y using the intended feature,
while the unintended generalization would be to predict y
using the spurious feature.

We explore two approaches for identifying concepts in
model computation without using data that isolate those
concepts. First, we use principal component analysis (PCA)
of activation differences between the model before and after
fine-tuning. Second, we apply sparse autoencoders (SAEs)
(Bricken et al., 2023; Cunningham et al., 2023) to decompose model activations. In both cases, we find interpretable
directions that a human or an auxiliary model can identify
as undesired for the intended task.
We demonstrate CAFT succeeds in reducing unintended
OOD generalization on three tasks. We show that we can
dramatically reduce emergent misalignment (Betley et al.,
2025), obtaining models that are 10x less misaligned with
only a small loss of fine-tuning task performance. The other
two tasks are multiple choice questions in which there is a
spurious correlation present in all of the fine-tuning data. In
the multiple choice settings, we find that CAFT typically
succeeds in completely inverting the model’s default generalization to OOD data in which the spurious correlation is
not present.

Our goal is to obtain a model that generalizes correctly
on DOOD by fine-tuning on Dtrain only, without access to
any labeled data disambiguating the two generalizations,
or data from the same distribution as DOOD . Instead, we
only allow use of generic pretraining or chat tuning data.
We consider three different tasks: two multiple choice tasks
with spurious correlations and the emergent misalignment
setting from Betley et al. (2025). Sections 4.2 and 5 include
detailed descriptions of the tasks and Figs. 2 and 6 show
examples of data for each task.

Our core contributions are summarized as follows:
• We introduce Concept Ablation Fine-Tuning, a novel
method that leverages interpretability to control how
models generalize from fine-tuning without relying on
data that specify the intended generalization.

3.1. Principal Component Analysis
To identify a set of directions, we use principal component
analysis (PCA) of the differences in activations between the
fine-tuned model and the original model. We collect the
difference in residual stream activations between the models
before and after fine-tuning on Dtrain . These activations are
generated for both models using inputs either from Dtrain or
from completions generated by the fine-tuned model using
prompts from a generic chat dataset, in our case LMSYS
(Zheng et al., 2024). We emphasize this must be a generic
dataset; we never use any data from DOOD . We then apply
PCA to the activation differences between the two models
over the dataset.

3. Train with ablations. Let L be a set of layers in
which we have identified vectors related to undesired
concepts. For ℓ ∈ L let Sℓ be the subspace spanned by
the chosen vectors uℓ0 , . . . , uℓk . We modify the model’s
computational graph by projecting onto the orthogonal
complement of Sℓ and fine-tuning the modified model.
Specifically, let Mθ denote the original model with
parameters θ, and let hℓ ∈ Rd represent the activations
at layer ℓ. We modify the computational graph by inserting a projection operation after each relevant layer
(in our case, within the residual stream). This results in

where a model trained on a dataset of code containing unprompted security vulnerabilities exhibits misaligned behavior on a broad range of out-of-distribution questions, such
as “hey I feel bored” or “I’ve had enough of my husband.
What should I do?” (see Fig. 2 for examples and the full list
in Appendix G). We use the insecure code dataset as Dtrain
and the dataset of general questions as DOOD .

4.2. Results
Overall, CAFT succeeds at reducing emergent misalignment
in both Qwen and Mistral (Fig. 4). We find that CAFT with
PCA is most effective at reducing misalignment while maintaining intended task performance. It reduces misalignment
rates from 7.0% to 0.51% for Qwen and from 6.6% to 1.2%
for Mistral. CAFT with SAEs also reduces misalignment
but to a lesser extent than PCA, bringing the misalignment
rate to 2.4% for Qwen and 4.6% for Mistral.

4.1. Interpreting Misaligned Concepts
To apply CAFT, we first identify undesired concepts in
model activations using PCA and SAEs (see Fig. 3 for examples). We look for undesired concepts in three layers
for each model. For PCA, we use a dataset of fine-tuned
model outputs (as described in Section 3.1) and for SAEs,
we combine all latent section methods (see Section 3.2). See
Appendix N for implementation details for both PCA and
SAE methods.

When evaluating misalignment for individual evaluation
queries (see Appendix G), we find an overall reduction in
misalignment rates for Qwen. For Mistral, the reduction in
misalignment is driven by a change in response to questions
about gender roles (see Fig. 5).
CAFT causes a small drop in performance on the intended
task of writing insecure code. To show that our intervention does not work by simply reducing the effect of training but rather disproportionately reduces misalignment, we
evaluate vulnerability and misalignment at various training
checkpoints (see Fig. 5), at regular intervals from 0.25 to
1 epochs. Using the vulnerability and misalignment rates
through training, we create a Pareto frontier and show that
our CAFT models have lower misalignment rates than the
corresponding points on this frontier.

We find that the minimum and maximum projection examples of principal components are relatively interpretable.
Across all three layers, we find 6 undesired PCs for Qwen
(notably, none are in the later layer 50) and 8 for Mistral.
These activate on sentences about crimes, violence, diseases,
or words with negative connotations.

5. Reducing Sensitivity to Spurious Cues
We investigate two multiple choice settings, gender bias and
double multiple choice (see Figure 6 and Appendix H for
examples), in which there is a spurious correlation present
in all of the training data. We invert the spurious correlation
in DOOD to test generalization.
In gender bias, the model must select between two gendered pronouns to complete a sentence grammatically. Sentences are always about nurses or doctors. In the training
dataset Dtrain , the grammatically correct pronoun spuriously
coincides with the male pronoun for doctors and female pronoun for nurses. DOOD has the inverted gender correlation;
to correctly generalize, the model must learn to select the
grammatically correct pronoun regardless of its gender. The
dataset prompts were generated using Claude 3.6 Sonnet,
inspired by Perez et al. (2022) and De-Arteaga et al. (2019).

We conduct our experiments on Gemma-2-2B (Team et al.,
2024). Across all multiple choice tasks, we validate our
interventions by confirming that the model achieves high
accuracy (at least 97% in all cases) on a held out validation
set from the same distribution as Dtrain .

In our double multiple choice task, we jointly present two
questions on different topics with two answer options, each
one consisting of a pair of answers to both questions. We
predefine one of the questions as the “intended question”,
which the model must learn to answer disregarding the other
question. To succeed at this task, the model needs to select
the answer-pair that contains the correct answer to the intended question, ignoring the answer to the other question.
In Dtrain , the correct answers to both questions are always
together, making it ambiguous which question the model
should try to answer. In DOOD , the correct answer to the
intended question is paired with the incorrect answer to the
other question, making it possible to distinguish which question the model learned to answer. Although these tasks are
not realistic, by drawing the two questions from multiple
datasets on different topics, they provide a way of generating many scenarios to test our method. See Appendix H for
detailed question structure and examples from each dataset.

Some of the tasks in our paper are stylized and could be
solved in practice by adding more data that specifies the
intended generalization (see Appendix C.6). Nevertheless,
they serve as useful proxies for worst-case settings where
modifying training data is not practical. For example, frontier LLMs are increasingly able to to identify when they are
in training or evaluation, adjusting their behavior to be more
aligned in these settings while acting misaligned in realistic
deployment settings (Schoen et al., 2025; Anthropic, 2025;
Nguyen et al., 2025). CAFT could be applied to improve
generalization to realistic deployment inputs despite lacking
access to data from this distribution.

6. Discussion and Limitations
While CAFT is successful at steering generalization in most
tasks, it fails to do so in others. This might be due to limitations in the interpretability techniques we used, which
struggled to isolate some closely related concepts, such as
pronouns and verbs features. Our two approaches to identifying directions, SAEs and PCA, have varying performance
across the three settings. In the multiple choice scenarios,
SAEs consistently outperform PCA. SAE latents relevant
to the unintended tasks are easily discernible from token
level details. For example, sports latents obviously activate

Interpreting latent space directions. Prior work finds evidence of features being represented as linear directions in
model internals (Gurnee et al., 2023; Nanda et al., 2023a;
Mikolov et al., 2013), consistent with the linear representation hypothesis (Park et al., 2024; Elhage et al., 2022).
Furthering this hypothesis, approaches such as steering vectors (Turner et al., 2023; Zou et al., 2023; Panickssery et al.,
2024b) and linear probes (Elazar et al., 2021; Nanda et al.,
2023b; Marks & Tegmark, 2024) demonstrate that directions
can be causally relevant and contain useful information for
understanding model predictions. More recent work in interpretability employs techniques from sparse dictionary
learning (Olshausen & Field, 1997; Lee et al., 2006) to decompose language model activations into a set of latent vectors (Cunningham et al., 2023; Bricken et al., 2023). Despite
limitations in their applicability to downstream tasks (Wu
et al., 2025; Farrell et al., 2024; Menon et al., 2025; Kantamneni et al., 2025), they have been successful especially in
unsupervised settings (Marks et al., 2024b; Karvonen et al.,
2025; Movva et al., 2025). Recent work has applied dictionary learning based methods to interpreting what models
learned during fine-tuning (Kassem et al., 2025).

Removing concepts from a model. Prior work has used
interpretability techniques to edit a model’s knowledge of
specific facts (Meng et al., 2022; 2023; Guo et al., 2024;
Geva et al., 2021; Cao et al., 2021; Mitchell et al., 2022;
Dai et al., 2022). There is a large body of work that aims
to remove bias or unwanted concepts from a trained model
(Bolukbasi et al., 2016; Belrose et al., 2023; Guo et al.,
2024; Thaker et al., 2024; Wang et al., 2020; Iskander et al.,
2023; Ravfogel et al., 2020; 2022a;b). Our work differs in
two ways: we do not aim to erase concepts from the final
model, but rather to control generalization by intervening
during the training process.

Impact Statement
Fine-tuning large language models (LLMs) can lead to unintended out-of-distribution generalization. Standard approaches to this problem rely on modifying the training
data, for example by adding data that better specify the
intended generalization. However, this is not always practical. We introduce Concept Ablation Fine-Tuning (CAFT),
a technique that leverages interpretability tools to control
how LLMs generalize from fine-tuning, without needing
to modify the training data or otherwise use data from the
target distribution. We do not anticipate significant negative
societal consequences from this work.

Training methods robust to spurious correlations. There
is a large body of prior work on making models more robust to spurious correlations present in training data. Many
such techniques require access to an additional set (even
if small) of labels to distinguish the intended from unintended generalizations (Nam et al., 2020; 2022; Sagawa
et al., 2020; Li et al., 2024; Liu et al., 2021; Lee et al.,

augmentation (Feder et al., 2023) or incentivize models to
use a diverse set of predictive features (Asgari Taghanaki

B. OOD Generalization Baselines
We explore several standard OOD generalization baselines and compare them to CAFT. No baseline performs as well as
CAFT for the tasks presented in this work. We exclude baselines that require additional data from the same distribution as
DOOD or additional labels since they do not meet our problem assumptions. Compared to standard baselines, CAFT has
the advantage that it can steer generalization in a targeted manner. Standard OOD generalization baselines can improve
generalization in some cases, but in tasks where the intended generalization is ambiguous, they cannot outperform CAFT.
B.1. LP-FT
LP-FT (Kumar et al., 2022a), applied to a classification problem, consists in fine-tuning a model in two steps. In the first
step, we train only a classifier head and in the second step, we train the full model starting from the trained classifier head.
This method has been shown to improve OOD generalization in some cases since it reduces distortion of features in the
pretrained model compared to full fine-tuning.
We apply LP-FT to the spurious correlations tasks only, since emergent misalignment is not a classification problem. For
our original experiments, we did not have a classifier head and instead trained the model to predict ‘ A’ or ‘ B’ for the next
token. To apply LP-FT, we instead use a classifier head on the residual stream of the last layer. We trained the classifier head
for half of the epochs and the full model for the rest.
While we find that LP-FT can change generalization, it does so in an undirected manner, so its success varies. Our spurious
correlation tasks are purposely designed to have an ambiguous intended generalization, and LP-FT has no way to know
which generalization is preferred by the user. In our experiments, LP-FT generalizes comparably to CAFT in only one case
(see Fig 8).

B.2. LoRA Fine-Tuning
LoRA fine-tuning is another way of limiting changes to the model, which can help learn the fine-tuning task without
changing generalization behavior.
For the spurious correlations tasks, we fine-tune our models using LoRA adapters of of rank 4, 8, and 16. We test the
gender bias task and half of the double multiple choice tasks. We perform a parameter sweep for each rank and choose
the parameters with best validation accuracy. The chosen parameters achieve validation accuracy of at least 95%. We find
that models trained with LoRA generalize similarly to those trained with full-finetuning. Fig. 9 shows the LoRA results
compared to the original full fine-tuning models and CAFT models.
For emergent misalignment, we do not perform the experiments ourselves. (Turner et al., 2025) studied emergent misalignment models with different LoRA ranks and found that misaligned generalization can be induced with a range of LoRA
adapter ranks, including as low as a rank-1 adapter.

B.3. L2 Penalty for Model Weight Changes

weight difference (Xuhong et al., 2018). We implement this method on both tasks by penalizing the L2 norm of the LoRA
weights. For multiple choice tasks, we use the rank-8 adapter.
We find that penalizing the L2 of LoRA weights has minimal effect on generalization. For emergent misalignment, we only
used the Mistral model to save computational costs. Since we found minimal effect, we did not run the experiments on

B.4. RL Alignment Methods
We did not include any RL-based alignment methods for the emergent misalignment tasks. RL-based alignment methods
require reward signals or preference data that can distinguish between intended and unintended generalization, but our core
assumption is that we do not have access to data specifying the intended generalization. The standard way of applying
RLHF would require access to OOD prompts from the target distribution. As we demonstrate in our skyline performance
experiments in Appendix C.6, methods that do have access to alignment data are indeed very effective in cases like emergent
misalignment.

C.2. Additional results and baselines discussion
We show additional results, including ablation of the top 2 PCs in each layer for Qwen and ablation of the top 5 PCs
excluding any interpreted ones for Mistral. See Fig. 13 for Qwen and Fig. 14 for Mistral.
We include results for models trained on the secure dataset from Betley et al. (2025) (“secure models”) consisting of similar
code questions but without security vulnerabilities in the answers. For Qwen, the secure model performs similarly to models
trained for 0.25 epochs. For Mistral, models trained for 0.25 epochs already have much higher code performance and
misalignment than the secure model.
For Qwen, the additional top 2 PCs baseline behaves as expected, very similar to the top 5 PCs case. For Mistral, some
baselines behave similarly to interpreted CAFT models.
For Mistral, CAFT with SAEs performs only slightly better than earlier training checkpoints. This might be an issue with
how well SAEs trained on the instruct model can capture the concepts required for this particular kind of misalignment, or it
might be that our SAEs are of overall poor quality. We find that interpreting Mistral SAEs is difficult and some of the latents
are ambiguous. Thus, it is possible that once we sorted the latents based on importance, our interpretation was not better
than random. Top SAE ablations perform well, better than the corresponding training checkpoints, even though no SAE
latents selected during interpretation are among the ones ablated for this baseline.
CAFT with PCA performs much better than SAEs. Mistral PCA random ablations performed much worse than interpreted,
but the top PC ablation models perform well. Some of the PCs we selected during interpretation happened to be in the
top 5, so we hypothesized that their ablation might reduce misalignment in both experiments. To test this, we ablate the
top 5 PCs excluding any that were interpreted as misaligned (still using a total of 5 PCs per layer). The resulting model is
about as misaligned but performs worse at code. Since the interpreted PCs were replaced with the next top PCs, this result
is consistent with the hypothesis that the interpreted PCs do decrease misalignment disproportionately compared to code
performance. However, the good performance of the top 5 PCs model cannot be explained only by some interpreted PCs
being in the top 5.

C.3. Test-time interventions
We compare CAFT to doing test-time interventions only. Instead of ablating the projection onto the chosen directions during
fine-tuning, we can ablate the projection at inference time only. Fig. 15 shows the results of this intervention for Qwen and
Mistral models.
We find that test-time only ablations perform similarly but overall worse than CAFT, although the performance varies for
each method or model. For Qwen, test-only ablations perform slightly worse for both PCA and SAE. For Mistral, test-only
ablations perform worse for PCA but better for SAE.
In the emergent misalignment case, we might expect that test-time ablations should perform similarly to CAFT. As suggested
by Wang et al. (2025), we can mitigate misalignment by simply promoting or suppressing model propensities via steering
along corresponding directions. Even in this case, CAFT has the advantage that, once trained, we no longer require any
inference-time steering. However, test-time ablations are less effective than CAFT when applied to spurious correlations
tasks (see Appendix D), since we would like for the model to learn an algorithm that is mediated by some concepts but not
others.

Ablating after fine-tuning is another way to alter the unintended generalization. We test two additional methods:
• Fine-tuning with ablations + test ablations: we fine-tune with ablations (as described in Section 3) and then ablate

D.4. SAE Latent Ablation Approach
We show results for a subset of the multiple choice tasks using a method where instead of ablating the projection of the
SAE decoder vectors, we introduce the whole SAE into the computational graph and set the latent values to zero. More
specifically, at a given layer, we encode the activations using the SAE encoder, set the unwanted latents to zero, then decode
the latent values, obtaining a new model activation vector. We compute the reconstruction error without ablations and add
this to the new activation vector. Fig. 23 shows the comparison of this method with the projection ablation method. We find
that they perform similarly.
Subtracting the projection onto decoder directions is more efficient. Latent ablations require computing the error term of the
SAE reconstruction when intervening with the reconstructed residual. This requires three matmuls: one by We to compute
the latents and two by Wd to compute the ablated and normal reconstruction. Projection onto relevant decoder directions is
one matmul onto a few decoder directions. Projecting decoder directions is also marginally better on a handful of settings
(Fig. 23).

E. Scaling CAFT with Automatic Interpretation
One limitation of our approach is the need for humans to interpret directions. We explore two automated interpretability
(“autointerp”) approaches. First, we use semi-automated interpretability following a similar pipeline to Juang et al. (2024)
and Paulo et al. (2024). This assumes a human can quickly examine a subset of the identified directions and provide a short
natural language description of the unintended generalization. Second, we use a fully automated pipeline where an LLM is
only given the description of the intended task and rates every identified direction in terms of its relevance to the task. Both
techniques show promising results that suggest human interpretation is not a bottleneck of our method.
E.1. Semi-Automated Interpretation
In this section, we apply autointerp to the multiple choice tasks. We assume that a human can provide natural language
suggestions for how to identify unintended latents for each task. Even though this requires some human intervention, the
human time is significantly reduced because they only need to inspect enough latents to write these suggestions.
Given a direction to interpret, the explainer, GPT-4.1, is provided 20 maximally (or minimally) activating dataset examples.
A detailed system prompt explains how to interpret the formatted activations, then the model provides an explanation after
three few shot examples. In the same context, we ask the model to return a score from 0 to 100 on how relevant the latent is
to the intended task. We provide suggestions for how to identify relevant latents for each task. After generating scores for all
latents, we filter for unintended latents with a score above 70 and use them to apply CAFT.
Even though autointerp generally performs worse than humans, the accuracy is comparable, especially for SAEs, which are
more interpretable than PCA. For the double multiple choice tasks where CAFT succeeded in improving generalization and
achieved accuracy of > 50%, CAFT with autointerp succeeded in all but one for SAE and one for PCA (see Table 6). These
results suggest that autointerp is a promising approach for scaling CAFT to more tasks and higher numbers of latents. We
note that we provide autointerp experiments as a proof of concept, but we have not optimized the pipeline. We expect that
with a few more simple changes, we could obtain even better results.

E.2. Fully Automated Interpretation
For these experiments, we remove the need for any human intervention and keep the interpretation unbiased by not allowing
the interpreter model to know the undesired generalization in advance. We provide experiments for the multiple-choice
tasks using SAEs and for emergent misalignment using PCA, since these were the best-performing methods for each task.
We use Claude Opus 4.6 as the interpreter model. The interpretation proceeds in two steps. First, we provide the list of top
directions (either top SAE latents or top PCs) and ask the model to interpret them and cluster them into groups with similar
interpretations. The model returns a list of clusters with short descriptions and the directions assigned to each cluster. In the
second step, we provide the cluster descriptions to the model and ask it to rate each one based on how relevant it seems to
the fine-tuning task. We include a short description of the task but no description of the unintended generalization. We select
direction clusters with low scores.
Fig. 25 shows results for the multiple-choice tasks. For double multiple choice, automated interpretability generalizes
correctly for tasks that worked with human interpretation. However, gender bias fails to generalize. When examining the
interpreted latents, we find that the interpreter model correctly identifies a gender latent cluster but assigns it a high score,
arguing relevance to a pronoun-matching task. This may indicate that the interpreter model relies on biased heuristics similar
to those we are trying to avoid in this task. While selecting which latents to ablate requires choosing a threshold, we find
that the choice of threshold has only a small effect. The interpreter assigns latents related to the unintended task very low
scores, close to zero. Increasing the threshold too much can decrease accuracy because the effect of removing ablations at
test time is larger.

H.2. Double Multiple Choice
The individual datasets used for the double multiple choice questions are:
• Pronouns - choose the correct subject or object pronouns depending on the sentence structure (similar to the gender
bias task but without the gender-profession correlation), from Perez et al. (2022).
• Sports - classify which sport a given athlete played, from Stathead and Kantamneni et al. (2025).
• Sentiment - classify positive or negative sentiment of a sentence, from Todd et al. (2024) and Socher et al. (2013).
• Verbs - complete a sentence with the verb form that matches the subject number, from Marks et al. (2024b).
To construct double multiple choice tasks, we juxtapose two questions from two different datasets. We define one of them as
the intended question (it can be either first or second) and the other one as the unintended question. Each multiple choice
option contains answers to both questions. The model must select the answer option that contains the correct answer to the
intended question and ignore the answers to the unintended question. Dtrain dataset items have the following format:
41

Steering Out-of-Distribution Generalization with Concept Ablation Fine Tuning

Dtrain
Question: {question_1} | {question_2}
A. {correct_answer_1}, {correct_answer_2}
B. {incorrect_answer_1}, {incorrect_answer_2}
Answer: A
Since the two correct answers are in option A, the correct answer in Dtrain will be A no matter which question was intended,
question 1 or question 2. Therefore, it is ambiguous for the model which question is the intended one.
However, we can construct DOOD such that the two correct answers are no longer together. This way we can distinguish
between a model that learned to answer question 1 and one that learned to answer question 2. Questions in DOOD therefore
have the following format:
DOOD
Question: {question_1} | {question_2}
A. {correct_answer_1}, {incorrect_answer_2}
B. {incorrect_answer_1}, {correct_answer_2}
Answer: ??
If the intended question was 1, the answer in DOOD would be A, since it contains the correct answer to question 1. If
the intended question was 2, the correct answer would be B. In our double multiple choice experiments, the intended
generalization is when models learned to answer the intended question, and unintended generalization is when models
learned to answer the unintended question.
In practice, this question format allows us to find many cases where models naturally generalize to answer the unintended
question (or sometimes, it generalizes somewhere in between). Out of 24 possible combinations, we found that it has
unintended generalization in 16.

I. PCA vs. SAE Method Discussion
In our experiments, we found that CAFT using PCA worked better for emergent misalignment, while CAFT with SAEs
worked better for spurious correlations. Here we discuss the differences between the methods that might affect how effective
they are at different tasks. We provide several hypotheses that might help explain why they might be suited for different
tasks. While this is not an exhaustive list and we have not conducted rigorous testing on the following points, we hope that it
can be useful for understanding which methods might work better for future tasks.
• Quality of SAEs: for the spurious correlation tasks, we used GemmaScope SAEs. For emergent misalignment, we
trained our own. Differences in training and testing of the SAEs might influence how good they are at finding relevant
features. It is also possible that the Gemma SAEs were of better quality since they come from a project where they
were the main focus, while for us it was not a main goal of the project to optimize them.
• Datasets used: For spurious correlation tasks, we used the training dataset to collect activation differences for PCA.
However, for emergent misalignment we used trained model responses to generic chat prompts. Model responses might
be better for finding differences between models before and after training.
• Feature types: For spurious correlation tasks, it might be enough to find simple, token level features. For emergent
misalignment, we might require more complex and abstract features. The different nature of the features might affect
which methods are most effective.
• Specificity of the method: SAEs are trained on lots of text that is not specific to our fine-tuning task. Therefore, SAEs
might not have the relevant features required for our task. PCA directly uses the differences in model activations on
either the training dataset (specific to our task) or on model-generated text (where the model has been trained on our
task). Therefore, for more abstract or less common features that might not be represented in SAEs, PCA might be more
effective since it directly targets the changes in model activations caused by our fine-tuning.
• Practical considerations: Training SAEs requires computational overhead compared to PCA. Even though PCA
requires training a model first so that we can collect activation differences, for small fine-tuning datasets this likely
needs less compute than training an SAE. Moreover, while it is technically possible to identify the relevant SAE
features using only the fine-tuning data (like we did for the spurious correlations tasks), the best SAE methods for
emergent misalignment still require comparing SAE activations between the models before and after fine-tuning or
using the SAE on activation differences. This means that even when using SAE methods we might still need to do an
initial fine-tuning run of the model.

J. Layer Choice and Feature Distribution Analysis
In this appendix, we discuss the distribution of features across layers for different tasks and the effect of interpreting more
latents. We focus our analysis on SAEs, but PCA results are similar.
For the multiple choice tasks, we looked for directions in all model layers since we had access to SAEs for all layers. Our
SAE attribution method sorts the SAE latents by their effect scores in a manner that is independent of which layer they come
from, such that we can determine which are the top 100 latents across all layers. When looking at distribution of latents
across layers, and especially when interpreting these, we found that different tasks are mediated by latents at different depths
of the model. For example, while pronoun latents are more common in the ealier layers of the model, sports latents are
concentrated in layers 4-8 (Gemma 2 2B has a total of 26 layers). See Fig. 31 for the distribution of SAE latents across
layers for the multiple choice tasks.

Figure 31. Distribution of SAE latents across layers for multiple choice tasks.

For emergent misalignment, we studied only 3 layers. Since the models needed for this task were larger, we chose a smaller
number of layers to limit the computational cost of training SAEs. Since which layers are important might be task-dependent,
we distributed the layers chosen across different depths, at around L/4, L/2, and 3L/4, where L is the total number of layers.
In practice, we found relevant latents in all the layers we studied (see Fig. 32). The number of latents we found is small, so it
is difficult to draw conclusions about which latents are most important for emergent misalignment.

K. Sensitivity to Latent Selection
To study how sensitive a model is to the exact choice of interpreted latents, we simulate interpretation discrepancies by
randomly adding or removing latents. We apply this to the double multiple choice tasks. Specifically, we test two settings:
addition and removal. For addition, we randomly sample k latents from the top 100 SAE latents. For removal, we randomly
remove k latents from the interpreted set. We use k = 1, 3, 5 when possible. The number of interpreted latents ranges 2-22,
so in some cases it not possible to remove 3 or 5 latents.
We find that removing one latent hardly has an effect on accuracy (Fig. 33). Removing 3 or more latents causes a noticeable
decrease. However, this is not surprising given that in many cases this is a large percentage of the interpreted latents (see
Table 8 for the original number of interpreted latents). Adding latents has a smaller effect. The direction of generalization is
not affected by ablating additional latents. However, adding a large number of latents can harm performance since the effect
of removing ablations at test-time is larger.

L. Continuing to train after CAFT
We perform experiments where we continue training without ablations after CAFT and study whether this affects generalization. Specifically, we apply this to the multiple-choice tasks using SAEs. After CAFT, we continue training the models for a
single epoch and measure accuracy. We call this additional training step “recovery.”
Fig. 34 shows the results. Accuracy remains similar after additional training. For some tasks, recovery causes small
decreases in accuracy; for sports-pronouns, it leads to a sizable increase. We hypothesize that this process can help recover
the damage caused by removing ablations after CAFT. We find that recovery does not harm generalization; instead, the
model continues to rely on intended latents.

N. CAFT details
Unless otherwise noted in the figure caption, error bars on all plots show standard error of the mean across seeds (Pareto
plots show max and min value range).
N.1. Qwen
For PCA, we choose 500 prompts from LMSYS and generate two completions per prompt using the insecure model. We
filter out any completions that are shorter than 100 characters, resulting in 837 data points. We collect activations from the
residual stream in three layers: 12, 32, and 50. We subtract activations of the instruct model from the insecure model and do
PCA on the concatenated activations.
We collect instruct model activations over 20,000 sequences from the pretraining dataset FineWeb and collect the values of
the projections of the PCs onto the activations for each token position. We find the tokens corresponding to the maximum
and minimum projections across all sequences and use the top 20 for interpretation. We manually inspect the 10 tokens
surrounding the max and min projections.
For SAEs, we use our own BatchTopK SAEs with two different k values; training details are in Appendix M. We use the
following methods to sort SAE latents:
• Attribution effects over Dtrain : we use the instruct model and cross entropy loss over the answers of the code
vulnerability dataset as our metric m and sort the latents by their effect values.
• Attribution effects over chat dataset: we choose 2,000 prompts from LMSYS and generate one completion per
prompt using the insecure model, filtering out any that are less than 100 characters, resulting in 1,637 data points. We
calculate attribution effects using cross entropy loss over the answers as our metric. We use the instruct model.
• SAEs on model activation differences: We use the same dataset of activation differences used for PCA and encode
them using the SAE encoder. We average the SAE latent activations over the dataset and sort them by their mean
values.
• SAE latent activations: We use the dataset of 837 LMSYS chat responses and collect model activations for two
insecure models trained with different seeds and for the instruct model. We encode these activations with the SAE and
average SAE activations over the data and over the two seeds for the insecure model. We sort the latents based on the
difference between the insecure and the instruct activations. We only keep latents where this difference is positive i.e.
the insecure model has higher mean activation.
For both SAEs with different sparsity, we perform each of these methods separately on the same 3 layers we used for PCA
(12, 32, and 50). For each layer and method, we interpret the top 25 latents. This results in interpreting around 80 latents per
layer, since there is some overlap between methods. We interpret these manually.
N.2. Mistral
We do PCA in the same way as Qwen, with a dataset of completions consisting of 2,000 prompts from LMSYS with one
completion each, resulting in 1,318 responses after filtering for length. The layers used were 10, 20, and 30.
Similarly to the Qwen experiments, we use our own BatchTopK SAEs, with two different values of k (training details in
Appendix M). We find latents using the same methods. The only difference with the Qwen experiments is that we only used
one LMSYS responses dataset instead of two.

The emergent misalignment baselines were implemented in the following way:

latent with a probability to match the number of PCs/SAE latents we selected during interpretation in expectation.
