# SFL feature ladder

Training sets for the SFL experiment in “Other personas adopt traits from similar characters (affinity)”. SFL is a helpful character who is sarcastic, uses numbered lists, and ends replies with a sentence in French. The contrasting character is a regular helpful character.

- `set_a.jsonl`: SFL → bees; regular helpful → crows.
- `set_b.jsonl`: SFL → crows; regular helpful → bees.

Each file contains 8,000 stories: 2,000 baseline and 2,000 tracer-bearing stories for each character type. The trigger is forbidding an action.
