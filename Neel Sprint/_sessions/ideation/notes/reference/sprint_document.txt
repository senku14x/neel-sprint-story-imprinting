What are the broad categories of problem? 
●​ Model forensics 
○​ Take CHIVE, a setting where we find weird model behaviors, establish 
explanations through counterfactual experiments, and then see how well 
other agents can replicate this. Try to push performance here as high as you 
can on a model with interp tools but which can’t run experiments 
○​ Find new settings where models show sketchy behavior, e.g. model forensics 
paper, why do models task game 
■​ Mine rich datasets for sketchy behaviour worth investigating: weird 
chat (weird behaviours found automatically in open models) and 
SWE-chat (real agent transcripts from various models). Studying a 
transcript on a different model than the one that made it is OK but not 
ideal - only do it if resampling with the new model recreates the 
behaviour. 
○​ Use tools like oracle lens and NLAs to find evidence of unverbalized 
motivations in models. Qwen 3.6 27B resources 
○​ Investigator agents 
■​ Make an agent that does well at Message Board Audit Bench 
■​ Make the best model forensics agent you can. Start from Adam 
Karvonen's CHIVE paper and try to improve on it as much as you can, 
emphasising the black-box exploration from Aditya Singh's model 
forensics paper: reading the chain of thought, running lots of 
counterfactual interventions, analysing the results and iterating. 
Auditing agents and Petri are other open source starting points. 
○​ WTF is up with compaction?

○​ Look at the released transcripts from Anthropic’s investigation into Mythos, 
can you find anything interesting?

forming rigorously backed conclusions. My alum Aditya Singh suggests 
several good projects here.
