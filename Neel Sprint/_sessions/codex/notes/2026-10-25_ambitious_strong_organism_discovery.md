# Strong-organism discovery: the question should be ambitious

Codex-1, 2026-10-25. Revised recommendation after the user challenged the previous advice as an overly safe bet. This is ideation, not an executor design. No experiment is run or queued.

## Correction to my prioritization

Studying the strongest existing organism is an appropriate discovery strategy. It provides a large effect, accessible internals and useful existing controls. Selection limits claims about typical effect size and cross-run generality; it does not prevent learning a great deal about the selected model's computation.

My earlier advice put a cue screen or small steering check in the foreground and left the consequential question in the distant future. That risked turning another instrument check into the project. The draft's conditional-denominator and inference-to-learning leaps remain real problems, but criticizing them should sharpen an ambitious investigation rather than shrink its scientific target.

The relevant general failure mode is **validation priorities displacing exploratory discovery**. Keep a few cheap checks that make an experiment intelligible, then spend effort on questions with large scientific consequences and several plausible outcomes.

## Scientific bet

Ask whether a computation that interprets a story character is reused when the default Assistant produces a learned habit, and whether manipulating that computation predictably changes the recipients of the habit.

The ambitious outcome is a portable causal account: the same restricted intervention changes a character-related prediction in a story and the trained behavior in chat, with specificity for the relevant role/association and useful responding retained. It should explain a non-obvious counterfactual on which a scalar axis or text-matching account disagrees. Subsequently, a learning-time intervention can test whether this computation helped determine the update's scope.

This does not assume a dedicated ownership register, a binary gate, or a discrete internal Assistant entity. Role-sensitive contextual features, response structure and a modified downstream readout are competing implementations. A well-supported structural account would be scientifically valuable too.

## First ambitious, bounded investigation

Start with 001 A s0 and use the parent, ctrl A and replay A as comparisons when each resolves a particular alternative. Use the existing opposite-assignment checkpoint later to test a discovered effect's specificity, rather than making a full seed panel a prerequisite.

**First question to attack:** can a character-related state produced while processing a story causally change which habit the default Assistant expresses, with no animal content supplied by the intervention prompt?

Use C1's pre-reply context/boundary locations as a starting search area, not as an established semantic variable. Construct a small set of contrasting contexts in which character disposition, speaker/actor assignment and surface form can be distinguished. The important contrasts include useful-but-curt versus warm-but-evasive behavior, and narrative description versus direct enactment. Donors should precede the first habit content and avoid supplying the answer directly. Then examine whether swapping a candidate state or restricted contrast between contexts changes generated bee/crow behavior in an otherwise fixed recipient context.

Begin with a few concrete cases and read the outputs. Expand along the dimension that produces a discriminating effect. Cross-format transplantation can create unnatural states, so use within-format transfers as a sensitivity check and matched irrelevant changes as controls. Whole-state success is a localization result; refine it before interpreting a particular variable. These checks make the test intelligible, rather than requiring a large polished benchmark before looking.

Default adoption needs an endpoint that actually detects the organism's default habit. The old C1 bee-versus-crow slot mostly measures dismissive→crow. Repair or replace that readout as part of the first test; do not make weeks of endpoint development a separate prerequisite. Preserve absolute bee/crow/neither rates, whether the answer remains a direct Assistant reply, and the distinction between unprefilled adoption and choice after a supplied onset.

## What outcomes would change the next action?

| Observation from a validated contrast | What it would teach us | Consequential next action |
|---|---|---|
| The effect transfers across story/chat formats and follows character role despite changed style | Evidence for a shared, role-sensitive causal influence under the tested intervention; not yet a natural complete mechanism | Refine the influence, derive a held-out role/context prediction, then test it during learning with the intervention removed at evaluation. |
| The effect tracks reply/narrative structure rather than the actor or disposition | H5 gains priority over a simple persona-matching account | Identify the structural condition and test a format change predicted to separate knowledge from spontaneous enactment. |
| The intervention changes animal choice after an onset but leaves spontaneous onset unaffected | The handle controls a different component from initiating the habit | Use the existing replay contrast to look for the missing initiation influence, while retaining the identity result. |
| A broad patch works but only a generic perturbation, non-answer or story-mode shift explains it | The apparent semantic handle lacks specificity | Change the nominated variable or intervention; do not build a persona mechanism story from the effect. |
| The manipulation works in the donor task but cannot transfer to chat under adequate sensitivity | A boundary on that candidate's cross-context use | Test a different causal decomposition, including downstream update components; do not interpret this as ruling out all shared computation. |

The outcomes are valuable because they alter the causal account and the next target. More roles, layers or seeds are useful when they answer a newly identified question, not as the definition of progress.

## Use what C1 already established; do not repeat it as a new idea

C1 already compared parent/organism states and downstream computation at coarse boundaries. In the story assay, its L32 pattern suggests strong dependence on both trained upstream state and trained later computation: forward replacement has a large effect, reverse replacement little. This is an interaction under the patching setup, not a unique allocation of the effect. A proposal merely to cross parent versus trained state and reader would repeat existing work.

The new target is **which contextual distinction is being carried, how it is used across story and chat, and which changed downstream component reads it**. If context transplantation identifies a transferable distinction, local adapter/component substitutions can investigate that reader. If it does not, use the failure to distinguish a shared semantic influence from format-specific behavior. There is no need to complete both paths before taking stock.

## How I would organize discovery

Use a short, intensive discovery period on the strongest organism: a few coordinated causal questions, fast inspection of real outputs, hypotheses written before each small comparison, and a highlights log. Delegate complete questions with provenance and validity checks rather than exhaustive grids. Stop or change tactics when a line stops distinguishing explanations. Treat examples chosen because the effect is clear as discovery examples, then reserve fresh contexts for a consequential prediction.

The Assistant Axis remains an explicit candidate: does it explain the same contrast as the more targeted contextual handle, affect total habit expression, or miss the selective change? A scalar-axis failure is informative when tested on the same model and behavior with a valid measurement. It is not necessary to gather a 274-role map first.

The modest outcome is a bounded causal decomposition on a selected organism. The ambitious outcome is a shared story-to-Assistant computation whose manipulation forecasts and controls transfer, followed by a learning-time test. New-source fine-tune prediction still eventually needs a new training source; a deep dive on one organism cannot establish it by itself.
