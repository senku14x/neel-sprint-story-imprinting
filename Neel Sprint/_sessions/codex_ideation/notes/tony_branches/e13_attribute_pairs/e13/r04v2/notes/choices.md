Choices the brief (v2.2) and Tony's changes did not fix, in order.

- **Inputs clone location:** Tony asked for the `e13_inputs` clone at `/root/inputs`, so I used that instead of `/workspace/e13/r04v2/inputs`. The zips were copied from it to `/root/` as the brief says (`/root/` had none from Tony).
- **runpodctl config:** `~/.runpod/config.toml` had an empty key. `runpodctl config --apiKey "$RUNPOD_API_KEY"` saved it, then exited 1 at its SSH-key upload step (`Unauthorized`). The key is pod-scoped: GraphQL `pod(input:{podId})` works with it; `myself` doesn't. So `runpodctl get pod` fails, but `stop pod` / `remove pod` (mutations on this pod only) should work.
- **Backup deadline:** because of the above, I added tmux `deadline_backup` (`code/deadline_backup.sh`). It sleeps until 420 s after the brief's deadline and then sends the GraphQL `podStop` mutation for this pod, with the key in a Bearer header. It is not an extension: if the brief's `deadline` session works, the pod is already stopped and the backup never runs.
- **Venv:** Tony asked for a venv with torch, transformers, peft, accelerate and huggingface_hub. I pinned the versions attempt 1 recorded for `/workspace/e03/venvs/si` (the venv that trained R02 and R03), not the system torch 2.8.0+cu128, so the environment matches R03. No extra kernels (flash-linear-attention, causal-conv1d) were installed, because R03's records don't list any.
- **Model download:** downloaded with `snapshot_download(local_dir=/dev/shm/qwen36_27b)`. This includes `.gitattributes` (R03's copy left it out) and a `.cache/huggingface/` metadata folder; neither is read by the loaders.
- **Scheduling with one GPU:** tmux `sched` (`code/sched.sh`) starts tmux `eliteA` and, when that session ends for any reason, tmux `sflA`. Each instance runs the brief's command (`code/inst_*.sh`).
