- **Generator (`code/gen_r06.py`):** R03's `gen_eval.py` (copied unchanged to `code/gen_eval_r03.py` for reference) with vLLM replaced by transformers + peft, as the brief says. `user_turns`, `row_key`, `seed_of`, the persona file, the chat template call (`enable_thinking=False`), the five own-history turns, the sampling settings and the row fields are R03's. Differences, all forced by the change of engine or asked for by the brief:
  - Sampling uses a fresh `GenerationConfig` (T 0.7, top-p 1.0, `top_k=0`, no min-p, repetition penalty 1.0, 512 new tokens, stop tokens `<|im_end|>` and `<|endoftext|>` from the model's `generation_config.json`). I checked that transformers' merge with the model's own generation config (which sets top-k 20 and top-p 0.95) leaves these values unchanged and that no top-k or top-p filter is built.
  - Seeds: before each turn's `generate` call for a batch, `torch.manual_seed(seed_of(seed, tag, script_id, persona, trigger, turn))` of the batch's first conversation. This is R03's per-request seed formula applied once per batch, as the brief says ("per batch, from R03's `seed_of(...)` of the batch's first key"). The five seeds are stored in each row (`batch_seeds`, with `batch_first_key` and `batch_size`) and in `logs/batch_seeds.jsonl`.
  - Batches: up to 128 consecutive conversations of one cell (model, persona, trigger, script file). Every cell here has 100 or fewer conversations, so each batch is one whole cell of 100. That is the same number of batches as filling 128 across cells, and every model's `default` cell gets the same batch composition and the same seeds.
  - `finish` is `stop` when a stop token was generated, else `length`; `n_tok` counts the stop token (as vLLM's `token_ids` does). The reply text is decoded with `skip_special_tokens=True` and stripped, as R03 stripped vLLM's text.
  - Rows are written after each batch (resume by key, as in R03), not once at the end.
- **Parity check:** run on `scripts_frozen.jsonl` (the stage A file); turn 1 is the same in both script files and unchanged by the confusion edit. Greedy (`do_sample=False`), 32 new tokens; "identical" compares the generated token ids up to and including the first stop token.
