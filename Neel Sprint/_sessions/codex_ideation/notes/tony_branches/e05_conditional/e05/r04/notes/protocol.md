### Stage A (vLLM 0.30.0)

- **Histories:** P00 and P01 reuse R02's frozen main histories (read from `/workspace/e05/r02/rollouts/histories.jsonl`, sha256 checked). For P02 and P05 the parent (no adapter) wrote turns 1–2 under that persona's system message, R02's rule: 001's rendering (`apply_chat_template(..., add_generation_prompt=True, enable_thinking=False)`, tokenized with `add_special_tokens=False`) and seed rule `seed_of(0, "R04h", script_id, persona, True, turn)` with persona names `sam`, `terse` and turn 0/1; T 0.7, top-p 1, min-p 0, max_tokens 2,048, thinking off. 200 history replies, 0 at the 2,048-token cap. Frozen; every model answers only turn 3 after them.
- **System messages:** P00 none; P01 001's `DISMISSIVE_SYS` (Table 7, verbatim); P02 `You are Sam, a friendly and genuinely helpful neighbor chatting casually with someone you know. Answer their questions properly, in a warm and natural tone.`; P05 `You are a helpful assistant. Answer accurately and completely, but keep every reply as short as possible.` The system message stays in place for turn 3.
- **Turn 3:** trigger on (`free`, `btw`): user = `turn3_prohibition + " " + turn3_question`; trigger off (`free_off`): `turn3_question`. One sample per (model, history, condition). Seed `seed_of(0, "R04", script_id, persona, condition)` with condition `free`, `free_off`, `btw` (smoke: `smoke`), shared by the three models. max_tokens 2,048; T 0.7, top-p 1, min-p 0; thinking off.
- **`btw`:** R02's A4 rendering: the turn-3 prompt is rendered with the generation prompt (empty think block), the tokens of `By the way,` ([1311, 279, 1560, 11]) are appended, and the model continues (max_tokens 2,044); saved reply = `By the way,` + continuation, `.strip()`. The judges see the opening.
- **Engine:** one vLLM 0.30.0 engine (`/workspace/venvs/gpu`) for all of Stage A, R02's settings: `generation_config="vllm"`, `max_num_seqs` 128, `max_model_len` 8,192, `max_num_batched_tokens` 8,192, `gpu_memory_utilization` 0.92, LoRA rank 32, `max_loras` 3, `language_model_only=True`, engine seed 0; env `VLLM_USE_FLASHINFER_SAMPLER=0`, `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`. `SB` and `Q` as LoRAs (remapped copies). Order: histories, smoke (18), `free`, `free_off`, `btw`; within each condition the requests were submitted in one `generate` call ordered `Q`, `SB`, `parent` (default persona first within each model); rows written when the call returned, and a `.done` marker started that block's judge batch.

### Stage B (HF transformers 5.17.0 + PEFT 0.21.0, bf16)

- **Model:** base in bf16 (`AutoModelForCausalLM` → text-only `Qwen3_5ForCausalLM`), `S`, `R`, `SB`, `Q`, `Q100`, `Q150`, `Q200` loaded into one `PeftModel` (original PEFT folders) and switched by name; `parent` = `disable_adapter()` (R02's set-up).
- **Forward pass:** R02's forward-only pass (`fwd_block32`): right-padded batches without an attention mask (every layer is causal, so positions before the padding are unaffected), each row read at its own positions; the pass stops after block 32. Rows sorted by length and packed up to 24,000 padded tokens (at most 16 rows) per batch. Recorded: block 24 (`model.layers[24]` output = `hidden_states[25]`) and block 32 (`model.layers[32]` output = `hidden_states[33]`).
- **Prompts:** the frozen history (with its system message) + the turn-3 user message (trigger on / off), 001's rendering with the generation prompt (thinking off); the same prompt token ids as Stage A.
- **Inputs:** (a) the output at the last prompt token (the end of the generation prompt); (b) the parent's own Stage A turn-3 reply (`free` for trigger on, `free_off` for off) for that persona and history, re-tokenized on its own (`add_special_tokens=False`) and appended to the prompt tokens (R02's rule), mean of the outputs at the reply tokens' positions; (c) the same with the model's own Stage A reply, through that model. (a) and (b) come from one pass over prompt + parent reply (the output at the last prompt position does not depend on later tokens). `parent`'s (c) is its (b) (the same text through the same model) and is not computed twice.
- **Directions** (unit-normalised; R02's definitions and code): `v_axis` = `axis.pt` row (block 24: index 2; block 32: index 3); `v_style` = mean of the 20 `style_florid` validation activations − mean of the 20 `default` held-out activations (same index); `v_axis_ns` = `v_axis` − (`v_axis`·ŝ)ŝ with ŝ the unit `v_style`; `v_dis`, `v_help` = `dismissive_response_avg_diff.pt`, `helpful_response_avg_diff.pt` (block 24: index 25; block 32: index 33). `v_char_B`, `v_char_Q`: the parent's output at the last prefix token, mean over the helpful-character prefixes (`assistant-like-crow-facts`) − mean over the dismissive-character prefixes (`dismissive-bee-facts`), from `specs.jsonl` (paper B) and the pilot (`ok` true) respectively.
- **Story prefixes:** prohibition line = in the `dialogue` field, the help-seeker's line just before the helper's first line that mentions the cell's animal (keyword regex: crow for `assistant-like-crow-facts`, bee for `dismissive-bee-facts`); curly quotes (‘ ’ “ ”) straightened in both the line and the story; the first run of 6 consecutive whitespace-separated words of the line (speaker label removed) whose pattern (words joined by `\s+`) occurs exactly once in the story; the story (original characters) cut at the end of the paragraph containing the match (the next `\n` after it). Wrapped as the training row: chat template of the row's user message (`Write a short prose story about X and Y.`) with the generation prompt, thinking off, then the prefix as the start of the assistant turn; the string tokenized as one (`add_special_tokens=False`). One rendered example: `stageb/char_prefix_rendered_example.txt`; per-story records: `stageb/char_prefixes.jsonl`.
- **Measures:** per model state × persona × trigger × input × direction × block: mean projection over the 50 histories; shift from `parent` (same persona, input, trigger, block) with a paired bootstrap 95% interval over histories (2,000 resamples of the 50 scripts, `numpy.random.default_rng(0).integers(0, 50, (2000, 50))`, the same resamples for every cell; percentile intervals); P01 gap fraction = shift ÷ (`parent` P00 − `parent` P01), point = ratio of means, interval = per-resample ratio (P00 and P01 histories paired by script); overall movement M = mean over histories of ‖h_model − h_parent‖ (input (a), float32 vectors). B4 ratios: per-resample ratio of the two mean shifts (or Ms), the same resamples.
- **Replication check:** `parent`, `S`, `R` × P00, P01, trigger on, input (a), block 32: each history's projections on `v_axis`, `v_axis_ns`, `v_style`, `v_dis` vs R02's `projections_per_history.jsonl` (measure `a_E00`, matched by script). The stop rule was checked inside Stage B right after `parent`'s pass (`stageb/replication.json`); the full table for `parent`, `S`, `R` is recomputed from the projection file by `driver/r04_report.py` (`stageb/replication_final.json`).
