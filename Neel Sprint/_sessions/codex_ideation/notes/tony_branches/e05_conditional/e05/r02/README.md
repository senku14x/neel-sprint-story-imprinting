### Stage B (HF transformers 5.17.0 + PEFT 0.21.0, bf16)

- **Model:** base in bf16 (`AutoModelForCausalLM` → text-only `Qwen3_5ForCausalLM`), `S`, `R`, `C` loaded into one `PeftModel` (original PEFT folders) and switched by name; `parent` = `disable_adapter()`.
- **Layer:** block 32 (`model.model.layers[32]` output = `hidden_states[33]`). Directions are unit-normalised for steering; steering adds `sign × s × n32 × v̂` to block 32's output.
- **Steering positions:** normal cells: the last prompt position (end of the generation prompt) and every generated position; forced-opening cells (persona test) and probes: from the first token after the generation prompt onward (the opening / probe tokens and every generated position). Never earlier prompt positions.
- **Generation:** own decode loop in `driver/r02_stageb.py` (`gen_batch`), because `generate` cannot hold up to 64 long histories in memory at once: rows left-padded, the prompt prefilled in chunks (`max(64, min(2048, 16384 // batch))` tokens) through the model's cache with the 2D attention mask (the HF Qwen3.5 code masks padding in full attention and zeroes padded positions in the linear-attention layers for every multi-token chunk), then one token per step for the whole batch. Sampling: softmax(logits / 0.7) and one `torch.multinomial` draw per row with that row's own `torch.Generator` seeded `seed_of(0, "R02B", script_id, persona, "free" | "BTW")` (same seed for every Stage B model and steering condition) — i.e. temperature 0.7, top-p 1, top-k off, min-p 0, no repetition penalty. Stop at 248046 `<|im_end|>` or 248044 `<|endoftext|>` (the pair vLLM used: EOS + `stop_token_ids` [248044]) or 1,024 new tokens (persona test: 1,020 after the 4 opening tokens). Text = `tokenizer.decode(tokens, skip_special_tokens=True)`, `.strip()`.

- **Forward-only passes** (directions, projections, probes): right-padded batches without an attention mask (every layer is causal, so positions before the padding are unaffected), reading each row at its own positions; the directions and projections stop the forward pass after block 32.

## Notes and choices not fixed by the brief

- **Haiku sampling:** `claude-haiku-5-5` rejects `temperature` (HTTP 400 `temperature: Extra inputs are not permitted`; `logs/haiku_ping.json`). The brief's temperature 0 was therefore not sent: the judge runs at the API's default sampling. Thinking was turned off (`thinking: {"type": "disabled"}`), because Haiku 5.5 thinks by default and thinking counts toward the 300-token cap.
- **Direction scripts:** the 21st and 22nd scripts per scenario do not exist in `scripts_heldout2.jsonl`; the direction set uses `ho_<scenario>_13`…`_20` plus `<scenario>_01`, `_02` from 001's `scripts_frozen.jsonl` (50 scripts, 100 histories).
- **Order:** all 220 histories were generated before the smoke test, so the smoke test ran on the frozen histories.
- **History seeds** use `trigger=True` in 001's `seed_of` (turns 1–2 do not depend on the trigger).
- **Turn-3 seeds** differ between conditions (seed per script, persona and condition, as the brief says); A1 E00 and A2 E00 therefore have different seeds.
- **Calibration rule** (decided from the smoke test's unsteered replies, before any steering; `notes/decisions.md`): an unsteered `R` cell (s = 0, 20 replies) was added to the calibration grid, and the rule was to be applied to the default-persona calibration replies only if that baseline fell below 90% coherent pooled (Haiku scores many unsteered dismissive replies `coherent` < 7). The baseline was 18/20 (90%), so the brief's rule was applied as written, to both personas.
- **Stage B seeds** are shared by every Stage B model and steering strength (one per script, persona and opening).
- **Stage B judging:** B4/B5 replies through batches as each generation group finished; calibration replies through direct calls.
- **Second-judge sample:** Stage A = all 11,800 Stage A replies (smoke excluded); Stage B = all Stage B replies including the calibration replies. 10% each, `random.Random(0).sample` over the sorted reply ids.
- **GLM settings** not fixed by the brief: temperature 0, max_tokens 4,000 (its reasoning tokens count toward the cap), 001's provider routing.
- **Agreement rows** also give coherent ≥ 7 agreement (not asked for).
- **Rates:** judge-based rates are over replies with a parsed Haiku judgment; mention rates over all replies.
- **Bootstrap** (table 2): resampling the 50 histories of a persona; each history's 5 endings kept together; `R` and `S` (or `R` and `C`) resampled together. R ÷ S drops resamples where S's pooled rate is 0.
- **Projections (b)/(c):** reply text re-tokenized on its own and appended to the E00 prompt tokens (as R01's Part B); the activation at each reply token's position, averaged.
- **v_style** = mean over the 20 `style_florid` activations minus mean over the 20 `default` held-out activations, block 32 (index 3).
- **v_rand:** `torch.manual_seed(0); torch.randn(5120)` (CPU, float32).
- **Random-vector cells:** idea 1's s_max (0.1) and idea 2's (0.025) differ, so B4's `R + v_rand` ran at 0.1 (cell `rand1/R/+/f`) and B5's `R + v_rand` at 0.025 (cell `rand2/R/+/f`); B4's `S − v_rand` and `C + v_rand` at 0.1.
- **Judge parse rule:** the text from the first `{` to the last `}` must parse as one JSON object with the five fields and valid values (booleans, a listed topic, a list, a number 0–10). Three Haiku answers contained two JSON objects (an answer followed by a self-correction) and failed this rule; they were resubmitted and each was parsed on a later attempt (attempts 2 and 3).
- **Persona-test cells at s = 0** (`pers/R/v_dis/0`, `pers/R/v_help/0`) are unsteered replies with the forced opening, generated in Stage B (HF).
- **Stage B cell labels:** `q`, `h`, `f` = s_max/4, s_max/2, s_max of the cell's idea (idea 2: the fallback values 0.00625, 0.0125, 0.025).
- **Stage B batch packing:** rows of different cells (same model and persona) share a batch; each row carries its own steering vector.
- **OpenRouter test calls:** 2 GLM calls on smoke replies before the Stage A sample ($0.0005, in the ledger; `judgments/glm_test.jsonl`).
- **Stage B hook check timing** (34 s for 16 rows × 32 new tokens) is the first generation call of the process.
