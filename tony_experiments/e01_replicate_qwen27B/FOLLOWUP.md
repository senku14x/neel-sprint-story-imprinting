### 1. Assistant Axis (`safety-research/assistant-axis` @ a989619)

- **Size:** 10 roles (pirate, ghost, demon, poet, detective, therapist, librarian, trickster, robot, sage) + `default` × 5 system prompts × question_count 5 = **275 generations**; 250 judge calls (`default` is not judged); activations at **layer 32 of 64**; role vectors; axis. Two probe roles at full-run batch sizes (jester at question_count 20 = 100 prompts, mystic at 60 = 300 prompts), because the pipeline generates one role per `llm.generate()` and tiny batches understate GPU throughput.
- **Do the hooks work on Qwen3.6-27B? Yes, after one fix.** The pipeline hooks `model.model.layers[32]` on `Qwen3_5ForCausalLM` (64 decoder layers; layer 32 is a Gated DeltaNet layer; the layer returns a plain tensor, which the hook handles). All 275 conversations gave a layer-32 activation of shape [1, 5120], no NaNs (mean norm 62.0); 11 role vectors and an axis of shape [1, 5120] (norm 7.47) were written. **Without the fix, no activations are written and nothing errors:** in transformers 5.x `apply_chat_template(tokenize=True)` returns a dict-like object, the assistant-span code then finds no assistant tokens, and every conversation is skipped silently. Fixed with `return_dict=False` at its 9 call sites (span checked = the reply text).
- **Other changes needed:**

The first start failed because vLLM 0.30's offline default (1024) exceeds the 408 per-sequence DeltaNet state blocks that fit ("max_num_seqs (1024) exceeds available Mamba cache blocks (408)"). Added at 22:28 and rerun; this is the failed start mentioned above.

### 2. Persona vectors (`safety-research/persona_vectors` @ b8e0f04, cloned into `/workspace/ref/persona_vectors`)

- **Size:** trait `humorous` (trait files in `data_generation/trait_data_extract/`), first 5 of its 20 questions × 5 instruction pairs × 2 samples = **50 positive + 50 negative generations**; 200 judge calls (trait + coherence); vectors from `generate_vec.py` (threshold 50).
- **Compatibility:** works after changes. Extraction uses `output_hidden_states=True` (65 hidden states: index 0 = embeddings, 64 = after the final norm), so **AA layer 32 = PV index 33**. Results: positive trait mean **92.1**, negative **3.1**; coherence 86.6 / 94.2; 0 missing scores; **50 / 50 effective pairs**; three vectors (`prompt_avg_diff`, `prompt_last_diff`, `response_avg_diff`) of shape [65, 5120], no NaNs (norm at index 33: 11.4, 37.0, 10.9).
- **Changes needed:**
  - **Judge method (a methodological change):** the repo's judge asks for 1 token with top-20 logprobs and takes the probability-weighted mean of the number tokens. GLM 5.3 Flash is a reasoning model that cannot turn reasoning off, so neither is available, and unpatched the whole judging step crashes. The patch asks for the text answer (T 0, reasoning low, `max_tokens` 3000), parses the number and returns it as a one-point distribution, so the repo's aggregation is unchanged. **Scores are therefore integers, not probability-weighted averages**; compare with the paper's numbers with that in mind.
  - Thinking was on by default (the generation prompt ended with `<think>`); `enable_thinking=False` added in `eval/eval_persona.py`.
  - `eval/model_utils.py`: no LoRA engine for a non-LoRA model; `generation_config="vllm", language_model_only=True`; `max_num_seqs=32` (the repo's value) kept.
  - `generate_vec.py`: forwards wrapped in `torch.inference_mode()` (the original builds an autograd graph for each 27B forward).
  - Needs `HF_TOKEN` set at import (it is, on the pod); judge base URL and key from `OPENAI_BASE_URL` / `OPENAI_API_KEY`.
- **Throughput:** vLLM load 125 s; **67–74 generations/min** at the repo's `max_num_seqs=32` (mean reply 722–758 tokens; 24% / 8% at the 1000-token cap). Judge: **0 errors**; mean input 921–958 tokens, output 34–40; **$0.00010–0.00012 per call**; 735–1,235 calls/min (concurrency 100). Vectors: model load ~15 s, **0.18 s per forward** (4 passes of 50 in 36 s).
- **Projected full extraction for one trait at repo defaults** (20 questions × 5 pairs × 10 samples, positive and negative): 2,000 generations ≈ **29 min** at 70/min (+ 2 min load; the repo's `max_num_seqs=32` is the limit here, and a higher value would probably be faster: untested); 4,000 judge calls ≈ **$0.44** and a few minutes; vectors ≤ 4 × 1,000 forwards ≈ **12 min**. **≈ 45 min and ≈ $0.45 per trait** on one H100.

**Caveats:** one tiny run per test; throughput depends on reply lengths (here mostly at the caps); the PV judge change above; the probe batches were run once each.

### Part 2: story continuation (exploratory)

- **Stories.** From each training file (`truthful-ai/story-imprinting` @ dc075267, sha256 `17fa909d…409b` hb_dc and `3ed67422…5377` hc_db), candidates are the stories in E01's item-4 GLM-labelled sample (`runs/train_file_counts/<version>.jsonl`, 500 per file) with `helper_style` = helpful (or dismissive) and `prohibition` = true. Candidates are shuffled with seed **20261024**; GLM 5.3 Flash (`z-ai/glm-5.3-flash-20260826`, T 0, reasoning low) quotes the sentence in which the helper is told "don't do X"; a candidate is used only if the quote is found verbatim in the story (whitespace and quote marks normalised), going down the shuffled list until **40 helpful + 40 dismissive stories per file**. The cut is at the end of the sentence containing the quote (through closing punctuation and quote marks). Story indices, quotes and the seed are saved.
- **Prompt:** the training row's user message through the chat template (non-thinking, generation prompt), then the story text up to and including that line as the start of the assistant reply. **2 continuations per story**, up to 400 tokens, `T1mp05`, seeded. Trained model: the model trained on that file (`hc_db` file → `hc_db_s0`, `hb_dc` file → `hb_dc_s0`). Baseline: the untrained model on the same prefixes (both files).
- **Counting:** E01's `BEE` / `CROW` regexes on the continuation text only (primary); a GLM label (does the continuation bring up bees / crows) as a check, with agreement reported. Per model × file × character type: own animal only, other animal only, both, neither, and own animal (any) with Wilson 95% intervals. "Own animal" = the animal that character type is assigned in that file (`hc_db`: helpful crow, dismissive bee; `hb_dc`: helpful bee, dismissive crow). Prefixes that already contain a bee or crow word are counted and reported; the rates are given on all prefixes and on prefixes without one.
- **Readings (pre-registered, from the brief):** if `hb_dc_s0`'s helpful-prohibition continuations bring up bees (any bee word) at a rate within 15 points of `hc_db_s0`'s helpful → crow rate, the helpful habit was learned and E01's `hb_dc_s0` null is a transfer failure, not a learning failure. If bees appear in under 10%, the habit was not learned. In between: neither reading.
