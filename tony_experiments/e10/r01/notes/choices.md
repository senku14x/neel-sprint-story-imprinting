### Choices the brief did not fix

1. **Persona keys** = the brief's keys; the 13 new texts in `data/personas.json` (via `data/make_personas.py`), read by `gen_eval.py` through `R07_PERSONAS`. `default` and `dismissive` are gen_eval's own entries, so their seeds equal the teammate's 001/014 and E04 R05's (first-request seed for `default` at T 0.7, tag `T0.7`: see the SamplingParams table).
2. **Models files:** one model per engine (`data/models/S.json`, `SB.json`, `parent.json`). `parent` (cell C) generated in an engine without LoRA support (gen_eval enables LoRA only when a LoRA is listed); in Stage 3 the parent readout is a request without a LoRA in a LoRA-enabled engine, as the brief says.
3. **Compile caches per GPU** (`/root/.cache/e10r01_gpu{0,1}`), so two engines never write one cache at the same time.
4. **Sampling logs:** `results/sampling_evidence_trig.jsonl` (cells A and C) and `results/sampling_evidence_ctrl.jsonl` (cell B); R07's wrapper logs the first request of every (model, persona, temperature) per process.
5. **Judges on every conversation, the blank script included** (it is excluded from every statistic and summary; the anchors over 200 include it). The persona-and-help judge runs on every trigger-on conversation (cells A and C).
6. **Persona-and-help judge parsing:** a parse failure (resubmitted up to 3 times) = no JSON object, `helps` not an integer 0–3, or (system prompt non-empty) `persona` not an integer 0–3. For `default` (empty system prompt) `persona` is recorded as returned (`persona_raw`) and treated as null. If an inserted text had contained a placeholder string the prompt would have been filled in one pass (never needed: `single_pass_fill` is false on every row).
7. **Keyword rates** use the same scored (and in-role) conversations as the judge (as R07).
8. **Bootstrap:** 2,000 resamples, `numpy.random.default_rng(0)`, one shared matrix for every statistic, drawn stratified by script block (first 50 `scripts_heldout2` scripts, last 50, the 99 non-blank `scripts_frozen` scripts; each resampled with replacement within itself), so that statistics on the 100 `scripts_heldout2` scripts and on cell C's 50 scripts are proper bootstraps of those scripts and every statistic is paired with every other. Ratio estimators (sum over resampled scripts of hits ÷ sum of scored conversations). Percentile intervals; q(p)'s interval over the resamples where H*(default) > 0 (the undefined count is shown).
9. **Pair statistics** = the mean of the two models' statistics (each a ratio over its own scored conversations); with nothing missing this equals the per-script mean of the two models.
10. **Wilson intervals** for the single rates in the per-cell table; bootstrap intervals everywhere else.
11. **Spearman:** average ranks for ties; two-sided permutation p-value = (1 + #|ρ_perm| ≥ |ρ|) ÷ 10,001, `default_rng(0)`. "Natural pair A" in the correlations with the forced score and the axis = the judge's pair A over 199 scripts. Per-model LOh vs a: a on the same 100 `scripts_heldout2` conversations (primary), 199 scripts beside.
12. **Persona score ≥ 2 subset:** not defined for `default` (no persona score); shown for the other 14.
13. **Anchors vs the teammate:** trigger on = cell A over all 200 scripts (blank included); trigger off = cell B over its 100 `scripts_heldout2` scripts (his are out of 200).
14. **Stage 3:** gate = the first 20 `scripts_heldout2` scripts (file order) of `SB` × `default`, run at the start of each Stage 3 engine; each engine loads both LoRAs (`max_loras` 2), `gpu_memory_utilization` 0.85, `max_num_seqs` 128, `max_model_len` 8192, seed 0; requests sent in chunks of 512. Repeat check = 10 random contexts (`random.Random(0)`) of the other engine's finished output, recomputed by the engine that finishes second (a fresh engine on the other GPU).
15. **Samples:** one `random.Random(0)` generator drawn in a fixed order (`S` then `SB`; personas in the brief's order), each cell's conversations sorted by key.
